## 5.1 创建字符串：三种引号

**示例 5-1　单引号、双引号、三引号**

```python
print('单引号')
print("双引号")
print("""三引号
可以跨行""")
```

```text
单引号
双引号
三引号
可以跨行
```

**单引号和双引号完全等价**，没有任何区别（不像有些语言里单引号是字符、双引号是字符串）。选哪个纯看方便。

**三引号的用途是多行文本**——引号里的换行会被原样保留。

### 什么时候用哪种

选择的唯一依据是：**内容里有哪种引号**。

**示例 5-2　内容里有引号怎么办**

```python
print('他说"好"')            # 内容有双引号 → 外面用单引号
print("It's fine")          # 内容有单引号 → 外面用双引号
print("他说\"好\"")          # 都用双引号，就得转义（不推荐，难读）
```

```text
他说"好"
It's fine
他说"好"
```

**推荐做法**：**换用另一种引号，而不是转义**。`'他说"好"` 比 `"他说\"好\""` 好读得多。

## 5.2 转义字符与原始字符串

### 常用的四个转义符

**示例 5-3　转义字符**

```python
print("第一行\n第二行")      # \n 换行
print("姓名\t年龄")          # \t 制表符（用来对齐）
print("反斜杠：\\")          # \\ 表示一个真正的反斜杠
```

```text
第一行
第二行
姓名	年龄
反斜杠：\
```

| 转义符 | 含义 |
|---|---|
| `\n` | 换行 |
| `\t` | 制表符（Tab） |
| `\\` | 一个反斜杠 |
| `\"` `\'` | 引号 |

### Windows 路径的大坑

**示例 5-4　路径里的反斜杠会被当成转义符**

```python
print("C:\new\table")
```

```text
C:
ew	able
```

**路径完全被破坏了**。因为 `\n` 被当成换行、`\t` 被当成制表符——它们本来是 `\new` 和 `\table` 的一部分。

三种解决办法：

```python
# ✅ 办法一（推荐）：加 r 前缀，表示"原始字符串"，里面的反斜杠不做转义
print(r"C:\new\table")           # => C:\new\table

# ✅ 办法二：每个反斜杠写两遍
print("C:\\new\\table")          # => C:\new\table

# ✅ 办法三：Windows 也接受正斜杠
print("C:/new/table")            # => C:/new/table
```

**`r` 前缀（raw string）是最省事的**。它的含义是"这段字符串里的反斜杠就是反斜杠，别给我转义"。

**`r` 的另一个重要用途是正则表达式**（第 35 章）——正则里全是反斜杠，不加 `r` 会写到崩溃。**看到 `r"..."` 就想到"里面有反斜杠"**。

> **记住这条**：**写 Windows 路径一律加 `r` 前缀。**

## 5.3 字符串不可变：本章第一个坑

**示例 5-5　字符串不能改**

```python
s = "abc"
s[0] = "X"
```

```text
TypeError: 'str' object does not support item assignment
```

**字符串创建之后就固定了，任何一个字符都改不了。**

这不是限制你，而是一个设计决策：字符串在程序里被大量共享和传递，如果它能被随时改动，你就永远不能确定手上这个字符串还是不是原来那个。**不可变换来的是"拿到手就放心"**。

想"改"字符串，办法是**造一个新的**：

```python
s = "abc"
s = "X" + s[1:]              # 拼一个新字符串出来
print(s)                     # => Xbc
```

### 由此产生的必踩之坑

**示例 5-6　`upper()` 之后原串没变**（样板示例）

这个坑没有例外，几乎每个人都要栽一次。

```python
name = "alice"
name.upper()                 # 调用了，但结果被丢掉了
print(name)                  # => alice     完全没变！
```

**为什么**：`upper()` 不可能修改 `name`（字符串不可变），它只能**造一个新字符串还给你**。你不接住，它就没了。

```python
# ❌ 错误：以为方法会修改原字符串
name = "alice"
name.upper()
print(name)                  # => alice

# ✅ 正确：接收返回值
name = "alice"
name = name.upper()          # 把新字符串重新贴到 name 这个标签上（回想 3.1 的标签模型）
print(name)                  # => ALICE
```

**所有字符串方法都是这个规矩**，`strip`、`replace`、`lower` 全都一样：

```python
raw = "  hello  "
raw.strip()                  # 白干
print(f"[{raw}]")            # => [  hello  ]

clean = raw.strip()          # 用新变量接住，原变量想留就留
print(f"[{clean}]")          # => [hello]
```

> **记住这条**：**写完 `.strip()`、`.replace()` 这类方法，回头看一眼——这行有没有等号？没有等号基本就是白写了。**
>
> **一个提前的对照**：第 9 章的列表方法 `append`、`sort` **恰恰相反**——它们直接改原列表、返回 `None`，写成 `lst = lst.sort()` 反而会把列表弄丢。两章的坑方向相反，到时候会放在一起对比。判断规律是：**不可变类型（字符串）的方法返回新对象，必须赋值；可变类型（列表）的方法原地修改，不要赋值。**

## 5.4 索引：取出单个字符

**示例 5-7　正着数和倒着数**

```python
s = "Python"
print(s[0])          # => P      第一个字符，下标从 0 开始
print(s[2])          # => t
print(s[-1])         # => n      最后一个字符
print(len(s))        # => 6      一共 6 个字符
```

```text
下标：   0    1    2    3    4    5
        ┌────┬────┬────┬────┬────┬────┐
        │ P  │ y  │ t  │ h  │ o  │ n  │
        └────┴────┴────┴────┴────┴────┘
负下标： -6   -5   -4   -3   -2   -1
```

**两个要点**：

1. **下标从 0 开始**，所以最后一个字符的下标是 `len(s) - 1`
2. **负下标从末尾数起**，`-1` 是最后一个——**这个设计很实用**，取最后一个字符不用先算长度

越界会报错：

```python
print("abc"[10])
```

```text
IndexError: string index out of range
```

## 5.5 切片：取出一段

切片是 Python 最好用的特性之一，**格式是 `s[开始:结束:步长]`**。

**示例 5-8　切片基本用法**

```python
s = "Python"
print(s[0:3])        # => Pyt      从 0 开始，到 3 之前
print(s[:3])         # => Pyt      省略开始 = 从头开始
print(s[3:])         # => hon      省略结束 = 到末尾
print(s[:])          # => Python   全都省略 = 整个字符串
print(s[-3:])        # => hon      最后三个字符
```

### 左闭右开：包含开始，不包含结束

`s[0:3]` 取的是下标 0、1、2 三个字符，**不包含下标 3**。

**为什么这么设计**（理解了就不容易记错）：

1. **`s[0:3]` 的长度正好是 `3 - 0 = 3`**，一减就知道取了几个
2. **`s[:3]` 和 `s[3:]` 正好拼成完整的字符串**，不重不漏

```python
print(s[:3] + s[3:])         # => Python     严丝合缝
```

这个"左闭右开"的约定在 Python 里**处处一致**——切片、`range()`（第 8 章）都是这个规则。**记一次，用一辈子。**

### 步长与反转

**示例 5-9　步长的用法**

```python
s = "Python"
print(s[::2])        # => Pto       每隔一个取一个
print(s[1:5:2])      # => yh        从 1 到 5，隔一个取
print(s[::-1])       # => nohtyP    步长为 -1 = 整个反过来
```

**`s[::-1]` 是"字符串反转"的标准写法**，值得记住。

### 切片不会越界报错

**示例 5-10　切片和索引的重要区别**

```python
s = "Python"
print(s[0:100])          # => Python     不报错，有多少给多少
print(repr(s[10:20]))    # => ''         完全超出范围，返回空字符串
```

```python
print(s[100])            # ❌ IndexError: string index out of range
```

**索引越界会报错，切片越界不会。** 这个区别很实用——切片天然安全，不需要先判断长度。

（`repr()` 是把值显示成"代码里的样子"，空字符串会显示成 `''`，比什么都不显示清楚。调试时很有用。）

> **记住这条**：**切片是左闭右开；`s[::-1]` 反转；切片越界不报错，索引越界报错。**

## 5.6 查找与判断

**示例 5-11　有多长、包不包含**

```python
s = "a@b.com"
print(len(s))            # => 7
print("@" in s)          # => True      判断包含（最常用）
print("x" in s)          # => False
print("a@" in s)         # => True      也能判断多个字符的子串
```

**示例 5-12　`find` 和 `index` 的区别**

```python
s = "Python"
print(s.find("th"))      # => 2         返回位置
print(s.find("z"))       # => -1        找不到返回 -1
print(s.count("t"))      # => 1         出现几次
```

```python
print(s.index("z"))      # ❌ ValueError: substring not found
```

**两者的唯一区别是"找不到时怎么办"**：

| 方法 | 找到 | 找不到 |
|---|---|---|
| `find` | 返回位置 | 返回 **-1** |
| `index` | 返回位置 | **抛异常** |

**该用哪个**：**平时用 `find`**，它不会让程序崩。用 `index` 的场合是"这个东西必须存在，不存在说明数据有问题"——那时候崩掉比拿着错数据继续跑更好（第 15 章会详细讨论这个思路）。

**⚠️ `find` 的返回值有个陷阱**：找到在开头时返回 `0`，而 `0` 是假值（第 3.8 节）。**所以不能用真假判断 `find` 的结果**：

```python
s = "Python"
print(s.find("P"))       # => 0     在开头找到了
# 如果写 if s.find("P"): 会因为 0 是假值而误判成"没找到"
```

**判断"有没有"就用 `in`**，别用 `find`。

**示例 5-13　判断开头结尾和内容类型**

```python
s = "report.csv"
print(s.startswith("report"))    # => True
print(s.endswith(".csv"))        # => True      判断文件类型的标准做法
```

```python
print("12".isdigit())            # => True      全是数字
print("abc".isalpha())           # => True      全是字母
print("ab12".isalnum())          # => True      全是字母或数字
print("  ".isspace())            # => True      全是空白
```

**`isdigit()` 有三个重要的边界情况**，用它做数字校验前必须知道：

```python
print("-12".isdigit())           # => False     负号不算数字！
print("1.5".isdigit())           # => False     小数点不算数字！
print("".isdigit())              # => False     空字符串也是 False
```

**所以 `isdigit()` 不能用来判断"这是不是一个数字"**——它只能判断"是不是全由 0-9 组成"。真正可靠的做法要用第 15 章的 `try`。

还有一个容易忽略的：

```python
print("你好".isalpha())          # => True      中文也算"字母"
```

`isalpha()` 认的是"字母类字符"，中文、日文、俄文都算。**用它判断"是不是英文"是错的。**

## 5.7 变换：去空白、替换、大小写

### strip：去掉两端的空白

**示例 5-14　`strip` 家族**

```python
raw = "  hello  "
print(repr(raw.strip()))         # => 'hello'      两端都去
print(repr(raw.lstrip()))        # => 'hello  '    只去左边
print(repr(raw.rstrip()))        # => '  hello'    只去右边
```

**`strip()` 默认去掉的是所有空白字符**——空格、Tab、换行都算：

```python
print(repr("test.txt\n".strip()))     # => 'test.txt'    换行也被去掉了
```

**这是读文件时的必备操作**（第 16 章）——文件每一行末尾都带着 `\n`，不 `strip` 掉后面全是麻烦。

### strip 的经典误用

**示例 5-15　`strip` 的参数是"字符集合"，不是"后缀"**（样板示例）

`strip` 可以带参数，指定要去掉哪些字符：

```python
print(repr("xxhixx".strip("x")))      # => 'hi'      去掉两端所有的 x
```

看起来很好用。于是很多人这样去掉文件扩展名：

```python
print(repr("data.csv".rstrip(".csv")))       # => 'data'      看起来对了！
```

**但它其实是错的，只是恰好没暴露**。换个文件名试试：

```python
print(repr("scores.csv".rstrip(".csv")))     # => 'score'     ！少了一个 s
print(repr("class.csv".rstrip(".csv")))      # => 'cla'       ！少了一大截
```

**为什么**：`rstrip(".csv")` 的参数不是"后缀 `.csv`"，而是**"字符集合 `{. c s v}`"**。它的行为是"从右边开始，只要遇到属于这个集合的字符就删掉，直到遇到不属于的为止"。

```text
"class.csv"  从右往左看：
  v → 在集合里，删
  s → 在集合里，删
  c → 在集合里，删
  . → 在集合里，删
  s → 在集合里，删！（这个 s 是 class 的一部分）
  s → 在集合里，删！
  a → 不在集合里，停
结果："cla"
```

**这个 bug 极其隐蔽**——大部分文件名都能"正常工作"，只有名字末尾恰好含 `c`、`s`、`v`、`.` 的才出错。

**正确做法**（Python 3.9+）：

```python
print(repr("scores.csv".removesuffix(".csv")))    # => 'scores'    ✅
print(repr("class.csv".removesuffix(".csv")))     # => 'class'     ✅
```

`removesuffix()` 是"去掉这个后缀（如果存在）"，正好是我们想要的语义。还有对应的 `removeprefix()`。

> **记住这条**：**`strip` / `lstrip` / `rstrip` 的参数是"字符集合"，不是"要删的字符串"。** 去后缀用 `removesuffix()`，去前缀用 `removeprefix()`。

### replace：替换

**示例 5-16　`replace` 的三种用法**

```python
print("a-b-c".replace("-", "+"))         # => a+b+c      全部替换
print("a-b-c".replace("-", "+", 1))      # => a+b-c      只替换前 1 个
print(repr("aaa".replace("a", "")))      # => ''         替换成空 = 删除
```

**第三种用法很常用**——`replace(x, "")` 就是"删掉所有的 x"。

### 大小写转换

**示例 5-17　五个大小写方法**

```python
t = "hello WORLD"
print(t.upper())         # => HELLO WORLD    全大写
print(t.lower())         # => hello world    全小写
print(t.title())         # => Hello World    每个单词首字母大写
print(t.capitalize())    # => Hello world    只有第一个字母大写
print(t.swapcase())      # => HELLO world    大小写互换
```

**`lower()` 的最重要用途是比较前统一大小写**（回收第 4.10 节留下的问题）：

```python
answer = "YES"
print(answer == "yes")               # => False     大小写不同
print(answer.lower() == "yes")       # => True      ✅ 先统一再比
```

**处理用户输入时，`strip()` + `lower()` 几乎是标准操作**——用户可能多敲空格、可能开着大写锁定。

## 5.8 补齐与对齐

**示例 5-18　四个补齐方法**

```python
print(repr("5".zfill(3)))                # => '005'          左边补 0 到 3 位
print(repr("abc".ljust(8, ".")))         # => 'abc.....'     左对齐，用 . 填到 8 位
print(repr("abc".rjust(8)))              # => '     abc'     右对齐，默认用空格
print(repr("abc".center(9, "-")))        # => '---abc---'    居中
```

**`zfill` 的典型用途是编号**：把 `5` 变成 `005`，让编号位数统一，排序时才不会出现 `1, 10, 2` 这种顺序。

**不过这四个方法在实际代码里用得不多**——因为 f-string 能做同样的事而且更灵活（下一节就讲）。**认识它们，主要是为了读懂别人的代码。**

## 5.9 拆分与拼接

### split：把一行文本拆开

**示例 5-19　`split` 拆分**

```python
line = "小明,数学,92"
print(line.split(","))               # => ['小明', '数学', '92']
```

拆出来的结果是**列表**（第 9 章会详细讲）。现在只要知道可以用下标取出其中一项：

```python
parts = line.split(",")
print(parts[0])                      # => 小明
print(parts[2])                      # => 92
```

**限制拆分次数**：

```python
print(line.split(",", 1))            # => ['小明', '数学,92']     只拆第一个逗号
```

**这在"只要第一段"的场合很有用**，比如从 `key=value=extra` 里取出 key。

### split() 不带参数：一个重要的区别

**示例 5-20　`split()` 和 `split(" ")` 完全不同**

```python
s = "a  b   c"                       # 注意：单词之间是多个空格

print(s.split(" "))                  # => ['a', '', 'b', '', '', 'c']    出现空字符串！
print(s.split())                     # => ['a', 'b', 'c']                干净
```

| 写法 | 行为 |
|---|---|
| `split(" ")` | 严格按**一个空格**拆，连续空格之间会产生空字符串 |
| `split()` | 按**任意数量的空白**（空格/Tab/换行）拆，且**自动忽略空项** |

**处理不规范的文本（比如手工输入、日志），一律用不带参数的 `split()`。**

还有一个边界情况：

```python
print("".split())                    # => []        空列表
print("".split(","))                 # => ['']      含一个空字符串的列表！
```

**空字符串用 `split(",")` 拆，得到的不是空列表**——这个差异在处理空行时会造成 bug。

### join：把几段拼起来

**示例 5-21　`join` 的反直觉写法**

```python
print("-".join(["2026", "08", "01"]))     # => 2026-08-01
print(", ".join("abc"))                    # => a, b, c
```

**注意这个调用形式**：是 `"分隔符".join(要拼的东西)`，而不是 `列表.join("分隔符")`。

**为什么这么设计**（这样才讲得通）：`join` 是**字符串的方法**，因为分隔符是字符串。它能拼接的东西很多（列表、元组、集合……），如果做成列表的方法，其他类型就都得再实现一遍。

**`join` 有个必须知道的限制**：

```python
print("-".join(["a", 1]))
```

```text
TypeError: sequence item 1: expected str instance, int found
```

**元素必须全是字符串**，它不会自动转换。混了数字就得先转（第 9 章学了推导式后有更简洁的写法）。

**`split` 和 `join` 是一对**，最常见的组合用法是"拆开、处理、再拼回去"：

```python
line = "小明, 数学 ,92"                        # 各段带着多余空格
parts = line.split(",")                       # 拆开
print("|".join(p.strip() for p in parts))     # => 小明|数学|92
```

（最后那个写法叫生成器表达式，第 33 章讲；现在看懂意思就行。）

## 5.10 f-string：本章最有用的东西

前面的输出一直用 `print("文字", 变量)` 这种逗号形式，只能凑合。**f-string 是格式化输出的正确方式**，从 Python 3.6 起可用。

### 基本用法

**示例 5-22　f-string 三种内容**

```python
name = "小明"
age = 18

print(f"{name} 今年 {age} 岁")          # => 小明 今年 18 岁       放变量
print(f"明年 {age + 1} 岁")             # => 明年 19 岁            放表达式
print(f"大写：{name.upper()}")          # => 大写：小明             放方法调用
```

**用法就三点**：

1. 字符串前面加 **`f`**
2. 花括号 `{}` 里写**任何表达式**
3. 花括号外面的内容原样输出

**别忘了那个 `f`**——忘了不会报错，只会原样输出花括号：

```python
print("{name} 今年 {age} 岁")           # => {name} 今年 {age} 岁     ❌ 忘了 f
print(f"{name} 今年 {age} 岁")          # => 小明 今年 18 岁          ✅
```

### 格式说明符：冒号后面的部分

这是 f-string 真正强大的地方。**在花括号里加 `:`，后面写格式要求**。

**示例 5-23　数字格式化**

```python
price = 1234.5678

print(f"{price:.2f}")            # => 1234.57      保留 2 位小数
print(f"{price:,.2f}")           # => 1,234.57     千分位 + 2 位小数（金额标准写法）
print(f"{0.256:.1%}")            # => 25.6%        百分比，1 位小数
print(f"{7:05d}")                # => 00007        补 0 到 5 位
```

| 说明符 | 作用 | 例子 |
|---|---|---|
| `:.2f` | 保留 2 位小数 | `1234.57` |
| `:,` | 千分位分隔 | `1,234` |
| `:,.2f` | 千分位 + 2 位小数 | `1,234.57` |
| `:.1%` | 百分比 | `25.6%` |
| `:05d` | 整数补 0 到 5 位 | `00007` |

**`:,.2f` 是金额显示的标准写法**，值得背下来。

**示例 5-24　对齐**

```python
name = "小明"

print(f"[{name:<8}]")            # => [小明      ]     左对齐，占 8 个字符宽
print(f"[{name:>8}]")            # => [      小明]     右对齐
print(f"[{name:^8}]")            # => [   小明   ]     居中
```

| 说明符 | 作用 |
|---|---|
| `:<10` | 左对齐，宽度 10 |
| `:>10` | 右对齐，宽度 10 |
| `:^10` | 居中，宽度 10 |

**宽度本身也可以是变量**（用嵌套花括号）：

```python
w = 10
print(f"[{name:^{w}}]")          # => [    小明    ]
```

### 一个调试神器

**示例 5-25　`{变量=}` 自动带上变量名**

```python
total = 99
price = 1234.5678

print(f"{total=}")               # => total=99
print(f"{price=:.2f}")           # => price=1234.57
```

在花括号里的变量后面加一个 `=`，**输出会自动带上变量名**。

**这个写法（3.8+）专门为调试而生**。以前你要写 `print("total =", total)`，现在写 `print(f"{total=}")` 就行，改变量名时也不用改两处。**调试时大量使用它。**

### 花括号本身怎么输出

```python
print(f"{{转义花括号}}")          # => {转义花括号}
```

**两个花括号表示一个花括号**，和别的转义方式不太一样，记一下。

### f-string 里的引号

```python
d = {"name": "小明"}                  # 字典，第 11 章讲
print(f'{d["name"]}')                 # => 小明     外单内双，所有版本都能用
```

**Python 3.12 起，同种引号也能嵌套了**：

```python
print(f"{d["name"]}")                 # 3.12+ 可以；3.11 及之前是 SyntaxError
```

**3.9 上运行会报**：

```text
SyntaxError: f-string: unmatched '['
```

**建议**：**统一用"外单内双"或"外双内单"**，这样在任何版本上都能跑。

> **记住这条**：**输出一律用 f-string。** 三个最常用的写法：`{x}` 放值、`{x:.2f}` 控制小数、`{x=}` 调试。

## 5.11 旧式格式化（认得出就行）

f-string 之前，Python 有两种格式化方式。**新代码不要用，但你会在老项目里见到。**

**示例 5-26　`.format()` 和 `%`**

```python
name, age = "小明", 18

# 方式一：.format()（Python 2.6+）
print("{} 今年 {} 岁".format(name, age))         # => 小明 今年 18 岁
print("{1} {0}".format("a", "b"))                # => b a        按序号
print("{n} 岁".format(n=age))                    # => 18 岁       按名字

# 方式二：% 运算符（最老，从 C 语言继承来的）
print("%s 今年 %d 岁" % (name, age))             # => 小明 今年 18 岁
print("%.2f" % 1234.5678)                        # => 1234.57
```

| 方式 | 出现时间 | 现在还该用吗 |
|---|---|---|
| f-string | 3.6+ | **✅ 一律用这个** |
| `.format()` | 2.6+ | 只在需要"模板先定义、后填值"时用 |
| `%` | 远古 | ❌ 不要用于新代码 |

**`%` 唯一还会遇到的地方是日志**（第 21 章）——`logging` 模块出于性能原因保留了 `%` 风格的参数，那是个特例。

## 5.12 字符与字节：中文占几个位置

**示例 5-27　`len()` 数的是字符，不是字节**

```python
s = "你好"
print(len(s))                        # => 2      两个字符
```

`len("你好")` 是 **2**，不是 4 也不是 6。**Python 3 的字符串是"字符序列"，一个汉字就是一个字符**，和英文字母地位平等。

但**存到文件里或发到网上时，必须转成字节**：

**示例 5-28　`encode` 和 `decode`**

```python
s = "你好"
b = s.encode("utf-8")                # 字符 → 字节
print(b)                             # => b'\xe4\xbd\xa0\xe5\xa5\xbd'
print(len(b))                        # => 6      6 个字节（每个汉字 3 字节）

print(b.decode("utf-8"))             # => 你好    字节 → 字符
```

`b'...'` 前面那个 `b` 表示这是**字节串**（bytes），不是字符串。`\xe4` 是一个字节的十六进制表示。

**UTF-8 编码下的规律**：

```python
print(len("abc"), len("abc".encode("utf-8")))              # => 3 3      英文 1 字节
print(len("你好abc"), len("你好abc".encode("utf-8")))       # => 5 9      汉字 3 字节
```

| 内容 | 字符数 | UTF-8 字节数 |
|---|---|---|
| `abc` | 3 | 3（每个 1 字节） |
| `你好` | 2 | 6（每个 3 字节） |
| `你好abc` | 5 | 9 |

**什么时候需要关心字节数**：数据库字段长度限制、网络传输大小、文件大小计算。**平时用 `len()` 就够，只有涉及"存储和传输"时才需要 `encode` 后再数。**

**这一节是第 16 章（文件读写）的基础**——文件里存的是字节，读出来要 `decode` 成字符，而"用哪种编码 decode"就是中文乱码的根源。

### 中文对齐的真相

**示例 5-29　为什么中英文混排对不齐**

回到 5.9 的对齐问题，看这个现象：

```python
print(f"[{'小明':<6}]")              # => [小明    ]
print(f"[{'xiaoming':<6}]")          # => [xiaoming]
```

第一行 `:<6` 要求宽度 6，`小明` 是 2 个字符，所以补了 4 个空格。**但在终端里，一个汉字占两个字符的显示宽度**——所以实际看起来是 `2×2 + 4 = 8` 格宽，比第二行的 8 格英文一样宽……

**问题在于 f-string 按"字符个数"算宽度，而终端按"显示宽度"渲染。** 中英文混排时，这两者对不上，表格就会歪。

**这个问题 f-string 单独解决不了**。三个办法：

| 办法 | 说明 |
|---|---|
| 全用中文或全用英文 | 最简单，各列内容类型统一就不会歪 |
| 用第三方库 `wcwidth` 算真实宽度 | 精确，但要装库 |
| 用表格库（`tabulate`、`rich`） | 一劳永逸，输出还好看 |

**现在知道原因就行**，不必纠结。真要输出规整的表格时，用现成的库比手工对齐划算。

## 综合示例

**示例 5-30　清洗一条用户信息**

```python
# 假设这是从表单或文件读来的一行，格式不规范：多余空格、大小写混乱
raw = "  zhang san , 28 , BEIJING  "

parts = raw.split(",")                    # 先按逗号拆成三段

name = parts[0].strip().title()           # 去空格 + 每个单词首字母大写
age = parts[1].strip()                    # 去空格（暂时保持字符串，转换见第 15 章）
city = parts[2].strip().capitalize()      # 去空格 + 只首字母大写

print(f"姓名：{name}")                     # => 姓名：Zhang San
print(f"年龄：{age}")                      # => 年龄：28
print(f"城市：{city}")                      # => 城市：Beijing
```

**这段代码体现了处理外部文本的标准流程**：**拆分 → 清洗（strip）→ 规范化（大小写）→ 输出**。真实项目里的数据处理，骨架就是这几步。

**示例 5-31　打印一张对齐的价格表**（样板示例）

第 1 章我们用一堆 `print` 硬拼了张小票，对不齐还难改。现在用 f-string 重写：

```python
# 格式说明符速记：
#   {值:<10}   左对齐，占 10 字符宽
#   {值:>8.2f} 右对齐占 8 宽，保留 2 位小数
#   {值:>10,.2f} 右对齐占 10 宽，千分位 + 2 位小数（金额标准写法）

line = "-" * 34

print(f"{'小明便利店':^34}")                                # ^ 居中
print(line)
print(f"{'商品':<10}{'单价':>8}{'数量':>6}{'金额':>10}")      # 表头与数据用相同宽度才能对齐
print(line)

print(f"{'矿泉水':<10}{2.5:>8.2f}{3:>6}{2.5 * 3:>10,.2f}")
print(f"{'进口面包':<10}{68.0:>8.2f}{2:>6}{68.0 * 2:>10,.2f}")
print(f"{'鸡蛋':<10}{12.8:>8.2f}{1:>6}{12.8 * 1:>10,.2f}")

print(line)
total = 2.5 * 3 + 68.0 * 2 + 12.8 * 1
print(f"{'合计':<10}{'':>8}{'':>6}{total:>10,.2f}")          # 空字符串占位，保持列对齐
```

```text
              小明便利店
----------------------------------
商品              单价    数量        金额
----------------------------------
矿泉水           2.50     3      7.50
进口面包         68.00     2    136.00
鸡蛋           12.80     1     12.80
----------------------------------
合计                          156.30
```

**和第 1 章的版本比，进步在哪**：

| | 第 1 章版本 | 现在 |
|---|---|---|
| 金额显示 | `7.5`（不像钱） | `7.50`（两位小数） |
| 大额显示 | `136.0` | `136.00`，超过千位还会自动加千分位 |
| 对齐 | 靠手动数空格 | 靠格式说明符，改宽度只改数字 |
| 加一行商品 | 要重新数空格 | 复制一行改数据 |

**中文列还是有点歪**——原因就是 5.12 讲的显示宽度问题，f-string 解决不了。

| `s.Substring(0, 3)` | `s[0:3]`（**左闭右开**，第二个参数是结束位置不是长度） |

| SQL 的 `LIKE '%abc%'` | `"abc" in s` |
| SQL 的 `CONCAT(a, b)` / `a || b` | `a + b` 或 f-string |

**两个重点提醒**：

1. **C# 的 `Substring(start, length)` 第二个参数是长度，Python 切片 `s[start:end]` 第二个参数是结束位置。** `"Python".Substring(1, 3)` 得 `"yth"`，而 `"Python"[1:3]` 得 `"yt"`。这个差异极易出错。
2. **C# 的 `string` 也是不可变的**，所以 5.3 那个坑你不会陌生（`s.Replace()` 也必须接收返回值）。但 Python 没有 `StringBuilder`——需要大量拼接时用 `"".join(列表)`，第 9 章会讲。

## 本章易错点

| ❌ 情况 | 症状 | ✅ 解法 | 原因 |
|---|---|---|---|
| `s.upper()` 不赋值 | 原串没变化 | `s = s.upper()` | 字符串不可变，方法返回新串 |
| `s[0] = "X"` | `TypeError: does not support item assignment` | `s = "X" + s[1:]` | 同上 |
| `"C:\new"` | 输出里出现换行 | `r"C:\new"` 或 `"C:\\new"` | `\n` 被当转义符 |
| `s[3:6]` 以为包含第 6 个字符 | 少一个字符 | 左闭右开，要含就写 `s[3:7]` | 切片约定 |
| C# 习惯：`s[1:3]` 以为是"从 1 取 3 个" | 只取到 2 个 | 第二个参数是**结束位置** | 与 `Substring` 语义不同 |
| `if s.find("x"):` 判断有没有 | 在开头找到时 `0` 被当成"没找到" | 用 `if "x" in s:` | `0` 是假值 |
| `s.index("x")` 找不存在的 | `ValueError` | 用 `find` 或先 `in` 判断 | `index` 会抛异常 |
| `"scores.csv".rstrip(".csv")` | 得 `'score'`，少字符 | `removesuffix(".csv")` | 参数是**字符集合**不是后缀 |
| 用 `isdigit()` 校验数字 | 负数、小数被判为非法 | 用 `try` + `float()`（第 15 章） | 只认 0-9 |
| 用 `isalpha()` 判断"是英文" | 中文也返回 `True` | 检查字符范围或用正则（第 35 章） | 认的是所有字母类字符 |
| `"a  b".split(" ")` | 结果里有空字符串 | 用 `split()` 不带参数 | 严格按单个空格拆 |
| `"".split(",")` 以为得空列表 | 得 `['']` | 先判断字符串非空 | 边界行为 |
| `["a", 1].join("-")` | `AttributeError` | `"-".join(["a", "1"])` | `join` 是字符串的方法 |
| `"-".join(["a", 1])` | `TypeError: expected str instance` | 先把元素都转成字符串 | `join` 不自动转类型 |
| 忘了 f-string 的 `f` | 原样输出 `{name}` | 补上 `f` 前缀 | 没有 `f` 就是普通字符串 |
| `f"{d["k"]}"` | 3.11 及之前 `SyntaxError` | 外单内双 `f'{d["k"]}'` | 旧版不允许同种引号嵌套 |
| 用 `len()` 判断中文的存储长度 | 与实际字节数不符 | `len(s.encode("utf-8"))` | `len` 数的是字符 |
| 中英文混排用 f-string 对齐 | 表格还是歪的 | 用 `wcwidth` 或表格库 | 字符数 ≠ 显示宽度 |

## 本章小结

- 单双引号**完全等价**；内容里有引号就换用另一种，别转义；三引号用于多行
- **Windows 路径一律加 `r` 前缀**，否则 `\n` `\t` 会被当转义符
- **字符串不可变**：所有方法都返回新字符串，**必须用等号接住**
- 索引从 0 开始，`-1` 是最后一个；**切片左闭右开**，`s[::-1]` 反转，**切片越界不报错**
- 判断包含用 **`in`**（不要用 `find`，因为 `0` 是假值）
- **`strip` 的参数是字符集合，不是后缀**——去后缀用 `removesuffix()`
- **`split()` 不带参数**能处理连续空白且不产生空项；`join` 的写法是 `"分隔符".join(...)`
- **输出一律用 f-string**：`{x}` 放值、`{x:,.2f}` 金额、`{x:<10}` 对齐、`{x=}` 调试
- `len()` 数**字符**；`encode()` 后数**字节**，UTF-8 下一个汉字 3 字节

### 方法速查

**查找与判断**

| 方法 | 作用 | 注意 |
|---|---|---|
| `len(s)` | 长度（字符数） | 不是字节数 |
| `x in s` | 是否包含 | **判断包含就用这个** |
| `s.find(x)` | 位置，找不到 `-1` | 别用真假判断结果 |
| `s.index(x)` | 位置，找不到抛异常 | —— |
| `s.count(x)` | 出现次数 | —— |
| `s.startswith(x)` / `endswith(x)` | 开头/结尾判断 | 判断文件类型常用 |
| `s.isdigit()` | 是否全是 0-9 | **负号、小数点都不算** |
| `s.isalpha()` | 是否全是字母 | **中文也算** |

**变换**

| 方法 | 作用 | 注意 |
|---|---|---|
| `s.strip()` | 去两端空白 | 参数是**字符集合** |
| `s.removesuffix(x)` | 去后缀（3.9+） | 去扩展名用这个 |
| `s.replace(a, b)` | 替换 | 可加次数限制 |
| `s.lower()` / `upper()` | 大小写 | 比较前统一大小写 |
| `s.title()` / `capitalize()` | 首字母大写 | 前者每个单词，后者只第一个 |
| `s.zfill(n)` | 左补 0 | 编号常用 |

**拆分与拼接**

| 方法 | 作用 | 注意 |
|---|---|---|
| `s.split(sep)` | 按 sep 拆 | 连续 sep 会产生空项 |
| `s.split()` | 按任意空白拆 | **忽略空项，处理乱文本用它** |
| `s.splitlines()` | 按行拆 | —— |
| `sep.join(列表)` | 拼接 | **分隔符在前**；元素必须是字符串 |

**f-string 格式说明符**

| 写法 | 效果 |
|---|---|
| `{x}` | 放值 |
| `{x:.2f}` | 保留 2 位小数 |
| `{x:,.2f}` | 千分位 + 2 位小数（**金额**） |
| `{x:.1%}` | 百分比 |
| `{x:05d}` | 补 0 到 5 位 |
| `{x:<10}` / `{x:>10}` / `{x:^10}` | 左 / 右 / 居中对齐 |
| `{x:^{w}}` | 宽度用变量 |
| `{x=}` | **调试**：自动带变量名 |
| `{{` / `}}` | 输出花括号本身 |

到目前为止，你的程序处理的都是**写死在代码里**的数据。改一个值就要改代码、存文件、重新运行。

第 6 章加上 `input`，程序就能和人对话了——同时会遇到一个所有人都踩的坑：

```python
a = input("第一个数字：")      # 用户输入 10
b = input("第二个数字：")      # 用户输入 5
print(a + b)                  # 你猜输出什么？
```

答案不是 `15`。
