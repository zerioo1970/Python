## 开篇：终于能装一批东西了

前面八章，你手上一直只有**单个的**值。想存"六个学生的成绩"，只能这样凑：

text = "88 95 70 62 99 78"          # 硬塞进一个字符串

total = 0

scores = [88, 95, 70, 62, 99, 78]

## 9.1 创建列表

**示例 9-1　用方括号装一批东西**

```python
scores = [88, 95, 70]
print(scores)                # => [88, 95, 70]
print(len(scores))           # => 3

print([])                    # => []            空列表
print([1, "a", True, 3.14])  # => [1, 'a', True, 3.14]    可以混装不同类型
```

**要点**：

- 用**方括号** `[]`，元素之间用逗号分隔
- `len()` 取元素个数（和字符串一样，第 5.6 节）
- **可以混装不同类型**，但实践中很少这么做——混装的列表处理起来要不停判断类型，很麻烦

**命名惯例**：列表变量用**复数**（`scores`、`names`、`items`），一看就知道装了多个。

## 9.2 索引：按位置取一个

**示例 9-2　正着数和倒着数**

```python
scores = [88, 95, 70]

print(scores[0])         # => 88     第一个
print(scores[1])         # => 95
print(scores[-1])        # => 70     最后一个
```

**规则和字符串完全一致**（第 5.4 节）：下标从 `0` 开始，负下标从末尾数起。

越界同样会报错：

```python
print([1, 2, 3][10])
```

```text
IndexError: list index out of range
```

## 9.3 切片：取一段出来

**示例 9-3　切片规则和字符串一模一样**

```python
scores = [88, 95, 70]

print(scores[0:2])       # => [88, 95]        左闭右开
print(scores[:2])        # => [88, 95]        省略开始
print(scores[1:])        # => [95, 70]        省略结束
print(scores[::-1])      # => [70, 95, 88]    反转
print(scores[::2])       # => [88, 70]        隔一个取
print(scores[0:100])     # => [88, 95, 70]    切片越界不报错
```

**这一节不需要重新学**——第 5.5 节讲的规则（左闭右开、负下标、步长、越界不报错）在列表上完全适用。

**为什么能通用**：字符串和列表都属于"**序列**"，Python 让所有序列共享同一套下标规则。**学一次，用到处。**

**注意切片的结果是一个新列表**（不是原列表的一部分），这一点在 9.14 节会变得重要。

## 9.4 列表能改，字符串不能

**这是列表和字符串最根本的区别。**

**示例 9-4　可变 vs 不可变**

```python
scores = [88, 95, 70]
scores[0] = 99                   # ✅ 直接改一个元素
print(scores)                    # => [99, 95, 70]
```

```python
s = "abc"
s[0] = "X"                       # ❌ TypeError: 'str' object does not support item assignment
```

**列表是可变的（mutable），字符串是不可变的（immutable）。**

**为什么设计成可变**：列表就是用来装"会变的一批数据"的——购物车会增删、成绩会修正。如果每次改动都要造一个新列表，代价太大。

**代价是什么**：可变带来了"共享修改"的坑——两个变量指向同一个列表时，改一个另一个也变。这就是 9.19 节要讲的内容，也是第 13 章的主题。

> **记住这条**：**字符串的方法返回新对象（必须赋值），列表的方法多半原地修改（不要赋值）。** 这条规律在 9.9 节会以最刺眼的方式出现。

## 9.5 增加元素

### `append`：末尾加一个

**示例 9-5　最常用的列表方法**

```python
lst = [1, 2]
lst.append(3)
print(lst)               # => [1, 2, 3]
```

**注意 `append` 是原地修改**——它直接改 `lst`，返回值是 `None`（9.9 节会讲这带来的坑）。

### `append` 一个列表会发生什么

**示例 9-6　`append` 只加"一个"元素**

```python
lst = [1, 2]
lst.append([4, 5])           # 把整个列表当成一个元素塞进去
print(lst)                   # => [1, 2, [4, 5]]     变成嵌套列表了
```

**得到的是嵌套列表**，而不是 `[1, 2, 4, 5]`。因为 `append` 的语义就是"在末尾加**一个**元素"，你给它一个列表，它就加一个列表进去。

想把另一个列表的元素**逐个**加进来，用 `extend`：

```python
lst = [1, 2]
lst.extend([4, 5])           # 把 [4, 5] 拆开，逐个加进来
print(lst)                   # => [1, 2, 4, 5]      ✅
```

| 方法 | 语义 | `[1,2]` 加 `[4,5]` 的结果 |
|---|---|---|
| `append(x)` | 加**一个**元素 | `[1, 2, [4, 5]]` |
| `extend(x)` | 把 x **拆开**逐个加 | `[1, 2, 4, 5]` |

### `extend` 一个字符串的"惊喜"

**示例 9-7　这个结果会让你意外**

```python
lst = [1, 2]
lst.extend("abc")
print(lst)                   # => [1, 2, 'a', 'b', 'c']
```

**字符串被拆成了三个字符！**

**为什么**：`extend` 会"把参数拆开逐个加"，而**字符串也是可迭代对象**（第 8.1 节）——拆开它就是一个个字符。

**想把整个字符串作为一个元素加进去，得用 `append`**：

```python
lst = [1, 2]
lst.append("abc")
print(lst)                   # => [1, 2, 'abc']     ✅
```

> **记住这条**：**加一个东西用 `append`，合并一批东西用 `extend`。** 遇到 `extend` 出现莫名其妙的字符，就是把字符串当成"一批"给它了。

### `insert`：插到指定位置

**示例 9-8　在中间插入**

```python
lst = [1, 2, 3]
lst.insert(0, 0)             # 在下标 0 处插入，原来的往后挪
print(lst)                   # => [0, 1, 2, 3]

lst.insert(2, 99)            # 在下标 2 处插入
print(lst)                   # => [0, 1, 99, 2, 3]
```

**性能提示**：在开头插入要把后面所有元素往后挪一格，列表很大时会明显变慢。**如果你频繁在开头插入，说明该用别的数据结构**（`collections.deque`，第 34 章）。**末尾追加（`append`）没有这个问题。**

### `+` 和 `*`

**示例 9-9　拼接和重复**

```python
print([1, 2] + [3, 4])       # => [1, 2, 3, 4]        拼接，产生新列表
print([0] * 5)               # => [0, 0, 0, 0, 0]     重复
print(["ab"] * 3)            # => ['ab', 'ab', 'ab']
```

**`[0] * 5` 是"造一个初始列表"的常用写法**——比写五个 0 简洁。

**注意 `+` 和 `extend` 的区别**：

| 写法 | 行为 |
|---|---|
| `a + b` | **产生新列表**，`a` 和 `b` 都不变 |
| `a.extend(b)` | **原地修改 `a`** |

**⚠️ `*` 用在嵌套列表上有个严重的坑**，见 9.18 节。

## 9.6 删除元素

**示例 9-10　`pop`：删掉并拿回来**

```python
lst = [10, 20, 30, 40]

x = lst.pop()                # 不带参数：删最后一个
print(x, lst)                # => 40 [10, 20, 30]

y = lst.pop(0)               # 带下标：删指定位置
print(y, lst)                # => 10 [20, 30]
```

**`pop` 是唯一会"返回被删元素"的删除方法**——所以它常用于"取出并处理"的场景。

**边界情况**：

```python
[].pop()
```

```text
IndexError: pop from empty list
```

**示例 9-11　`remove`：按值删**

```python
lst = [1, 2, 2, 3]
lst.remove(2)                # 按值删，只删第一个匹配的
print(lst)                   # => [1, 2, 3]      注意还剩一个 2
```

**两个要点**：

1. **`remove` 按值删，不是按位置**（`pop` 才是按位置）
2. **只删第一个匹配项**——想删掉所有相同的值，得用推导式（9.20 节）

值不存在会报错：

```python
[1, 2].remove(9)
```

```text
ValueError: list.remove(x): x not in list
```

**示例 9-12　`del` 和 `clear`**

```python
lst = [1, 2, 3, 4, 5]

del lst[0]                   # 删一个
print(lst)                   # => [2, 3, 4, 5]

del lst[1:3]                 # 删一段（切片）
print(lst)                   # => [2, 5]

lst.clear()                  # 清空，但列表还在
print(lst)                   # => []
```

**四种删除方式的区别**：

| 写法 | 按什么删 | 返回被删的值吗 | 特点 |
|---|---|---|---|
| `lst.pop()` / `pop(i)` | 位置 | ✅ 返回 | 唯一能拿回值的 |
| `lst.remove(x)` | **值** | ❌ | 只删第一个匹配 |
| `del lst[i]` / `del lst[a:b]` | 位置 | ❌ | 能删一整段 |
| `lst.clear()` | 全删 | ❌ | 列表变空但仍存在 |

（还有 `del lst` 是删掉整个变量名，回收第 3.10 节。）

## 9.7 修改元素

**示例 9-13　按位置改**

```python
lst = [88, 95, 70]
lst[0] = 99
print(lst)                   # => [99, 95, 70]
```

**示例 9-14　切片赋值能改变长度**

这是列表特有的能力：

```python
lst = [1, 2, 3, 4, 5]
lst[1:3] = [7, 8, 9]         # 用 3 个元素替换原来的 2 个
print(lst)                   # => [1, 7, 8, 9, 4, 5]      列表变长了
```

```python
lst = [1, 2, 3, 4, 5]
lst[1:3] = []                # 用空列表替换一段 = 删掉那一段
print(lst)                   # => [1, 4, 5]
```

**被替换的段和新内容的长度不必相等**——列表会自动伸缩。

**说实话，这个写法用得不多**（不太直观），但读别人代码时可能遇到。`lst[a:b] = []` 等价于 `del lst[a:b]`，后者更清楚。

## 9.8 查找与统计

**示例 9-15　`in` / `index` / `count`**

```python
lst = [88, 95, 70, 95]

print(95 in lst)             # => True      判断存在（最常用）
print(60 in lst)             # => False

print(lst.index(95))         # => 1         第一个 95 的位置
print(lst.count(95))         # => 2         95 出现了几次
```

**`index` 找不到会报错**：

```python
[1, 2].index(9)
```

```text
ValueError: 9 is not in list
```

**⚠️ 列表没有 `find` 方法**（字符串才有）：

```python
[1, 2].find(1)
```

```text
AttributeError: 'list' object has no attribute 'find'
```

**所以判断"在不在"必须用 `in`**，不能像字符串那样用 `find` 返回 -1。想安全地取位置，先用 `in` 判断：

```python
if 95 in lst:
    print(lst.index(95))
```

**示例 9-16　一行求和求最值**

```python
lst = [88, 95, 70, 95]

print(len(lst))                      # => 4
print(sum(lst))                      # => 348
print(max(lst))                      # => 95
print(min(lst))                      # => 70
print(sum(lst) / len(lst))           # => 87.0     平均值
```

**这四个函数把第 8 章手写的累加器全替代了**。回头看第 8.11 节那三个循环（求和、计数、找最值），现在都是一行。

**那第 8 章白学了吗？** 不是——**你得先理解"结果是怎么攒出来的"，才能在这几个函数不够用时自己写**。比如"统计满足某个条件的个数"、"累加到超过阈值就停"，还是得写循环。

**示例 9-17　空列表的边界**

```python
print(sum([]))               # => 0        空列表求和是 0，合理
```

```python
print(max([]))
```

```text
ValueError: max() iterable argument is empty
```

**`sum([])` 得 0，但 `max([])` 报错。** 这个不对称是合理的：空列表的"和"可以定义为 0，但"最大值"无法定义。

> **记住这条**：**对可能为空的列表用 `max` / `min` 前，先判断非空。**

## 9.9 排序：`sort` 与 `sorted`

**这一节是本章最容易踩坑的地方。**

**示例 9-18　`sort()` 原地排序**

```python
lst = [88, 95, 70]
lst.sort()
print(lst)                   # => [70, 88, 95]      原列表被改了
```

**示例 9-19　`lst = lst.sort()` 把列表弄丢了**（样板示例）

第 5.6 节我们学过：`s.upper()` 不改原字符串，**必须**写 `s = s.upper()`。列表这里**恰好相反**，同样的习惯会害人：

```python
# ❌ 错误：sort() 是原地排序，返回的是 None
a = [88, 95, 70]
b = a.sort()
print(b)                     # => None       列表没了！
print(a)                     # => [70, 88, 95]
```

**`sort()` 直接在原列表上排好序，不需要也没有返回新列表**——它返回 `None`。你把 `None` 赋给 `b`，`b` 就成了空值。

```python
print([88, 95, 70].sort())   # => None       直接看它的返回值
```

**正确写法有两种，取决于你要不要保留原顺序**：

```python
# ✅ 写法一：原地排序，不要赋值
a = [88, 95, 70]
a.sort()                     # 这一行不能有等号
print(a)                     # => [70, 88, 95]

# ✅ 写法二：要保留原列表，用 sorted() 生成新的
c = [88, 95, 70]
d = sorted(c)
print(d)                     # => [70, 88, 95]
print(c)                     # => [88, 95, 70]      原列表纹丝不动
```

### 把两章的坑并排放在一起

| 操作 | 行为 | 返回值 | 正确用法 |
|---|---|---|---|
| `s.upper()`（字符串） | 造新字符串 | **新字符串** | `s = s.upper()` **必须赋值** |
| `s.replace(...)`（字符串） | 造新字符串 | **新字符串** | 必须赋值 |
| `lst.sort()`（列表） | **原地改** | **`None`** | 不要赋值 |
| `lst.append(x)`（列表） | **原地改** | **`None`** | 不要赋值 |
| `lst.reverse()`（列表） | **原地改** | **`None`** | 不要赋值 |
| `sorted(lst)`（内置函数） | 造新列表 | **新列表** | **必须赋值** |

> **记住这条**：**不可变类型（字符串）的方法返回新对象，必须赋值；可变类型（列表）的方法多半原地修改并返回 `None`，不要赋值。**
>
> **一个通用自查技巧**：不确定时，`print` 一下方法的返回值。**看到 `None` 就说明它是原地修改的，那一行不该有等号。**

### 排序参数

**示例 9-20　降序、按长度、忽略大小写**

```python
print(sorted([88, 95, 70], reverse=True))         # => [95, 88, 70]     降序

words = ["banana", "apple", "Cherry"]
print(sorted(words, key=len))                     # => ['apple', 'banana', 'Cherry']  按长度
print(sorted(words))                              # => ['Cherry', 'apple', 'banana']  默认
print(sorted(words, key=str.lower))               # => ['apple', 'banana', 'Cherry']  忽略大小写
```

**注意默认排序把 `Cherry` 排到了最前面**——这就是第 4.10 节讲的原因：

```python
print(ord("C"), ord("a"))    # => 67 97       大写字母的编码更小
```

**所有大写字母都小于所有小写字母**，所以给人名排序时必须 `key=str.lower`，否则 `Zhang` 会排在 `alice` 前面。

`key` 参数的完整用法（包括多级排序）在第 25 章。**现在只要会用 `key=len` 和 `key=str.lower` 这两个常见形式。**

**示例 9-21　混装类型不能排序**

```python
[1, "a"].sort()
```

```text
TypeError: '<' not supported between instances of 'str' and 'int'
```

**排序要能两两比较大小**，而数字和字符串之间没有大小关系。**保证列表元素类型一致**。

## 9.10 三种"倒过来"

**示例 9-22　三个写法的区别**

```python
a = [1, 2, 3]
a.reverse()                          # 原地反转，返回 None
print(a)                             # => [3, 2, 1]

b = [1, 2, 3]
print(list(reversed(b)))             # => [3, 2, 1]      返回迭代器
print(b)                             # => [1, 2, 3]      原列表不变

c = [1, 2, 3]
print(c[::-1])                       # => [3, 2, 1]      切片，产生新列表
print(c)                             # => [1, 2, 3]      原列表不变
```

| 写法 | 改原列表吗 | 返回什么 | 什么时候用 |
|---|---|---|---|
| `lst.reverse()` | **改** | `None` | 就是要把原列表倒过来 |
| `reversed(lst)` | 不改 | 迭代器（**不复制数据**） | 只是要**倒着遍历**（第 8.14 节） |
| `lst[::-1]` | 不改 | **新列表** | 需要一个倒序的副本 |

## 9.12 遍历时不能改列表

**示例 9-24　边遍历边删除的诡异结果**（样板示例）

需求：删掉列表里所有的 0。最自然的写法是错的：

```python
# ❌ 错误：一边遍历一边删除
nums = [1, 0, 0, 2, 3]
for n in nums:
    if n == 0:
        nums.remove(n)

print(nums)                  # => [1, 0, 2, 3]      还剩一个 0！
```

**为什么漏掉一个**？因为 `for` 循环内部是**按下标往后走**的，而 `remove` 把后面的元素**往前挪了一格**：

| 轮次 | 循环走到下标 | 当时的列表 | 取到的元素 | 动作 |
|---|---|---|---|---|
| 1 | 0 | `[1, 0, 0, 2, 3]` | `1` | 不删 |
| 2 | 1 | `[1, 0, 0, 2, 3]` | `0` | 删掉 → 列表变 `[1, 0, 2, 3]` |
| 3 | 2 | `[1, 0, 2, 3]` | `2` | **第二个 0 挪到下标 1 了，被跳过** |
| 4 | 3 | `[1, 0, 2, 3]` | `3` | 不删 |

**删除让"当前位置"和"下一个元素"错开了一格**，于是紧跟在被删元素后面的那个永远不会被检查。

### 三种正确做法

```python
# ✅ 做法一：倒着遍历（从后往前删，挪动的都是处理过的部分）
nums = [1, 0, 0, 2, 3]
for i in range(len(nums) - 1, -1, -1):
    if nums[i] == 0:
        del nums[i]
print(nums)                  # => [1, 2, 3]

# ✅ 做法二：遍历一份副本，改原列表
nums = [1, 0, 0, 2, 3]
for n in nums[:]:            # 注意这个 [:]，去掉就又错了
    if n == 0:
        nums.remove(n)
print(nums)                  # => [1, 2, 3]

# ✅ 做法三（推荐）：不删了，直接生成新列表
nums = [1, 0, 0, 2, 3]
nums = [n for n in nums if n != 0]
print(nums)                  # => [1, 2, 3]
```

**第三种最好，三个理由**：**没有下标就没有下标错乱的可能**；一行说清意图（"留下所有不等于 0 的"）；不修改原数据，不会牵连别处。

（第三种用的是"列表推导式"，9.20 节讲。）

> **记住这条**：**遍历一个列表的时候，不要增删这个列表。** 需要筛选就生成新列表。
>
> **这个原则对字典和集合同样适用**（第 11、12 章）——而且字典更严格，边遍历边改会**直接报错**。

## 9.14 `[[0]*3]*3` 的陷阱

**示例 9-26　改一个变三个**

想造一个 3×3 的全 0 表格，`*` 看起来很方便：

```python
# ❌ 错误：用 * 复制嵌套列表
bad = [[0] * 3] * 3
print(bad)                   # => [[0, 0, 0], [0, 0, 0], [0, 0, 0]]   看起来对

bad[0][0] = 99               # 只想改第一行第一个
print(bad)                   # => [[99, 0, 0], [99, 0, 0], [99, 0, 0]]
```

**三行全变了！**

**为什么**：

```python
print(bad[0] is bad[1])      # => True      三行其实是同一个列表对象
```

**`*` 复制的是"引用"，不是"内容"**。`[[0]*3] * 3` 造出的三行，全都指向同一个 `[0,0,0]` 列表——改任何一行，三行都变。

**正确做法**：用推导式，让每一行都是新建的：

```python
# ✅ 正确
good = [[0] * 3 for _ in range(3)]
good[0][0] = 99
print(good)                  # => [[99, 0, 0], [0, 0, 0], [0, 0, 0]]
print(good[0] is good[1])    # => False     三行是独立的对象
```

**注意 `[0] * 3` 本身没问题**——因为 `0` 是不可变的数字，复制引用和复制内容没区别。**只有元素是可变对象（列表、字典）时，`*` 才有这个坑。**

> **记住这条**：**造嵌套列表用推导式 `[[0]*3 for _ in range(3)]`，不要用 `[[0]*3]*3`。**
>
> （那个 `_` 是"我不需要这个变量"的惯例写法，回收第 8 章——这里只是要重复 3 次，不关心是第几次。）

## 9.15 `b = a` 之后改 `b`，`a` 也变了

**这就是第 3 章埋下的伏笔。**

**示例 9-27　现象**

```python
a = [1, 2, 3]
b = a                        # 看起来像"复制一份给 b"
b.append(4)

print(a)                     # => [1, 2, 3, 4]      a 也变了！
print(b)                     # => [1, 2, 3, 4]
print(a is b)                # => True              它们是同一个对象
```

**为什么**：回到第 3.1 节的标签模型——**`=` 是贴标签，不是复制**。`b = a` 只是给同一个列表贴了第二张标签，通过任何一张标签修改，另一张都看得到。

**临时的自保办法**：用切片拷贝

```python
a = [1, 2, 3]
b = a[:]                     # 切片产生一个新列表
b.append(4)

print(a)                     # => [1, 2, 3]         ✅ 原列表不受影响
print(b)                     # => [1, 2, 3, 4]
print(a is b)                # => False
```

**为什么说是"临时"办法**：`a[:]` 只复制了**最外面那一层**。如果列表里装的是列表（二维），内层还是共享的——那个问题和它的完整解法在**第 13 章**。

> **记住这条**：**`b = a` 不是复制。** 需要一份独立的副本时，最简单的写法是 `b = a[:]`（但只对单层列表够用）。

## 9.16 列表推导式（最简形式）

**示例 9-28　它就是"循环 + append"的缩写**

```python
lst = [1, 2, 3, 4, 5]

# 普通循环写法
doubled = []
for x in lst:
    doubled.append(x * 2)
print(doubled)                       # => [2, 4, 6, 8, 10]

# 推导式写法：完全等价
print([x * 2 for x in lst])          # => [2, 4, 6, 8, 10]
```

**结构对照**：

```text
[   x * 2      for x in lst   ]
     ↑              ↑
  对每个元素做什么   从哪儿取元素
```

**读法**：从中间的 `for` 开始读——"对 `lst` 里的每个 `x`，取 `x * 2`，收集成一个列表"。

**示例 9-29　带 `if` 过滤**

```python
lst = [1, 2, 3, 4, 5]

print([x for x in lst if x % 2 == 0])          # => [2, 4]        只留偶数
print([x * 10 for x in lst if x % 2 == 0])     # => [20, 40]      过滤 + 转换
```

**`if` 放在最后**，含义是"只收集满足条件的"。

**什么时候用推导式**：**"从一批数据得到另一批数据"**——转换、过滤，或者两者一起。这是推导式最擅长的事，也是它在真实代码里出现频率极高的原因。

**什么时候别用**：逻辑复杂、需要多行、或者有多重条件时——老实写循环。**推导式的价值是"一眼看出在做什么"，一旦看不出来就失去了意义。**

（推导式的进阶写法——多重循环、嵌套、可读性红线——在第 25 章。）

## 9.17 列表与字符串互转

**示例 9-30　三个互转操作**

print("小明,小红,小刚".split(","))        # => ['小明', '小红', '小刚']    字符串 → 列表

nums = [1, 2, 3]

    print()
    print("购物清单：", end="")
    if items:                                     # 回收第 7.7 节：空列表是假

| ❌ 情况 | 症状 | ✅ 解法 | 原因 |
|---|---|---|---|
| **`lst = lst.sort()`** | `lst` 变成 `None` | `lst.sort()` 不赋值，或用 `sorted()` | `sort` 原地改并返回 `None` |

## 本章小结

- 列表用 `[]` 创建，**索引和切片规则和字符串完全一致**（左闭右开、负下标、越界不报错）
- **列表可变、字符串不可变**——这是两者最根本的区别
- 增：`append`（一个）、`extend`（一批，**注意字符串会被拆开**）、`insert`、`+`、`*`
- 删：`pop`（按位置，**返回被删的值**）、`remove`（按值，只删第一个）、`del`、`clear`
- 查：**判断存在用 `in`**（列表没有 `find`），`index` 找不到会**报错**
- 统计：`len` / `sum` / `max` / `min`——**替代了第 8 章手写的累加器**；注意 `max([])` 会报错
- **`sort()` 原地排序返回 `None`，`sorted()` 返回新列表**——这是本章最容易踩的坑
- **遍历列表时不要增删它**；需要筛选就用推导式生成新列表
- **`[[0]*3]*3` 会让三行联动**，造嵌套列表用推导式
- **`b = a` 不是复制**，单层列表可以用 `b = a[:]`（完整解法见第 13 章）
- 列表推导式 `[表达式 for x in 可迭代对象 if 条件]` 就是"循环 + append"的缩写

### 方法速查

**增删改**

| 写法 | 作用 | 返回值 |
|---|---|---|
| `lst.append(x)` | 末尾加一个 | `None` |
| `lst.extend(其他)` | 合并一批 | `None` |
| `lst.insert(i, x)` | 插到位置 i | `None` |
| `lst.pop()` / `pop(i)` | 删并**返回**被删的值 | 被删的元素 |
| `lst.remove(x)` | 按值删第一个 | `None` |
| `del lst[i]` / `del lst[a:b]` | 删一个 / 删一段 | —— |
| `lst.clear()` | 清空 | `None` |
| `lst[i] = x` | 改一个 | —— |
| `lst[a:b] = [...]` | 换一段（**可改变长度**） | —— |

**查与统计**

| 写法 | 作用 | 注意 |
|---|---|---|
| `x in lst` | 判断存在 | **判断存在就用它** |
| `lst.index(x)` | 位置 | 找不到抛 `ValueError` |
| `lst.count(x)` | 出现次数 | 循环里用它会很慢 |
| `len(lst)` | 元素个数 | —— |
| `sum(lst)` | 求和 | `sum([])` 是 0 |
| `max(lst)` / `min(lst)` | 最值 | **空列表会报错** |

**排序与反转**

| 写法 | 改原列表吗 | 返回值 |
|---|---|---|
| `lst.sort()` | **改** | `None` |
| `sorted(lst)` | 不改 | **新列表** |
| `sorted(lst, reverse=True)` | 不改 | 降序新列表 |
| `sorted(lst, key=len)` | 不改 | 按长度排 |
| `sorted(lst, key=str.lower)` | 不改 | 忽略大小写 |
| `lst.reverse()` | **改** | `None` |
| `reversed(lst)` | 不改 | 迭代器 |
| `lst[::-1]` | 不改 | 新列表 |

## 下一章预告

列表能装能改，很好用——**但正因为它能改，把它交给别人时你就没法保证数据不被动**。

第 10 章讲元组：一个**故意不让你改**的列表。听起来像是功能变少了，但正是这个限制让它能干一件列表干不了的事——**当字典的键**（第 11 章会用到）。

顺便你会看到一个反直觉的现象：
