## 开篇：用名字取数据，而不是数位置

列表和元组都是**按位置**取数据。想拿小明的分数，你得先知道他排第几个：

```python
names = ["小明", "小红", "小刚"]
scores = [92, 88, 76]

i = names.index("小明")          # 先找出他在第几位
print(scores[i])                 # 再用这个位置去另一个列表里取
```

**两个列表靠下标对应**——一旦有人插入或删除一条，两个列表就错位了，而且不会报错。

现实中我们想说的其实是：**"给我小明的分数"**。

```python
scores = {"小明": 92, "小红": 88, "小刚": 76}
print(scores["小明"])            # => 92
```

**这就是字典。** 它是 Python 里和列表并列最常用的数据结构。

**最好的类比是现实中的字典/电话簿**：你不会从第一页数到第 37 页去找"苹果"，你直接翻到"苹"字。

本章还会兑现两个承诺：第 9 章那个"用 `count` 统计词频"的低效写法（9.33 节），以及第 10.8 节埋下的伏笔——**为什么元组能当键，列表不能**。

## 11.1 创建字典

**示例 11-1　键值对**

```python
student = {"name": "小明", "age": 18, "score": 92}

print(student)               # => {'name': '小明', 'age': 18, 'score': 92}
print(len(student))          # => 3        有几对
```

**格式**：`{键: 值, 键: 值}`——**花括号**、键值之间用冒号、对之间用逗号。

```python
print({})                    # => {}                          空字典
print(dict(name="小红", age=17))    # => {'name': '小红', 'age': 17}    另一种写法
```

**术语**：`"name"` 是**键**（key），`"小明"` 是**值**（value），合起来叫一个**键值对**。

## 11.2 取值：三种方式，三种失败行为

**这一节是本章最容易踩坑的地方**，因为三种方式在"键不存在"时表现完全不同。

### 方式一：`[]` —— 取不到就报错

**示例 11-2　按名字取值**

```python
student = {"name": "小明", "score": 92}

print(student["name"])       # => 小明
print(student["score"])      # => 92
```

**和列表对照**：`lst[0]` 用位置，`d["name"]` 用名字。方括号里放什么，决定了你是"按位置"还是"按名字"取。

**示例 11-3　键不存在会报错**

```python
print({"a": 1}["b"])
```

```text
KeyError: 'b'
```

**`KeyError` 会把找不到的那个键打出来**（这里是 `'b'`），排查时很有用。

### 方式二：`get()` —— 取不到给默认值

**示例 11-4　`get` 不会报错**

```python
student = {"name": "小明", "score": 92}

print(student.get("name"))              # => 小明
print(student.get("phone"))             # => None            取不到返回 None
print(student.get("phone", "未填写"))    # => 未填写           指定默认值
```

**`get` 的第二个参数是"取不到时返回什么"**，不写就是 `None`。

### 方式三：`setdefault()` —— 会偷偷改字典

**示例 11-5　三种方式对照**（样板示例）

```python
d = {"a": 1}
print("原始:", d)                                        # => 原始: {'a': 1}

print("[] 取存在的:", d["a"])                             # => [] 取存在的: 1

print("get 取不存在的:", d.get("b"), " 字典现在:", d)
# => get 取不存在的: None  字典现在: {'a': 1}

print("setdefault 取不存在的:", d.setdefault("b", 99), " 字典现在:", d)
# => setdefault 取不存在的: 99  字典现在: {'a': 1, 'b': 99}
```

**注意最后一行——字典被写入了一个新键！**

`setdefault(k, 默认值)` 的行为是："**如果 k 不存在，就把它以默认值写进字典**，然后返回它的值"。

| 方式 | 键存在时 | 键不存在时 | 会改字典吗 |
|---|---|---|---|
| `d[k]` | 返回值 | **抛 `KeyError`** | 不会 |
| `d.get(k)` | 返回值 | 返回 `None` | 不会 |
| `d.get(k, 默认)` | 返回值 | 返回默认值 | 不会 |
| **`d.setdefault(k, 默认)`** | 返回值 | 返回默认值 | **会写入！** |

### 该用哪个

| 场景 | 用哪个 | 理由 |
|---|---|---|
| **这个键必须存在**，不存在说明数据有问题 | `d[k]` | **让它早点崩**，比拿着错数据继续跑好（第 15 章会详细讨论这个思路） |
| 键可能没有，缺了就用默认值 | `d.get(k, 默认)` | 最常用 |
| 需要"没有就初始化再用" | `setdefault` | **只在 11.13 节那个分组场景里真正好用**，其他时候容易误用 |

> **记住这条**：**平时用 `get`，明确要求存在时用 `[]`，`setdefault` 只在分组时用。**
>
> **`setdefault` 最常见的误用**：只想取个值看看，结果字典里悄悄多了一堆键。

## 11.3 `in` 查的是键，不是值

**示例 11-6　这是高频误解**

```python
d = {"name": "小明", "age": 18}

print("name" in d)               # => True
print("小明" in d)                # => False    ← 值不算！
print("小明" in d.values())       # => True     ← 查值要这么写
```

**`in` 对字典查的是键。** 这符合字典的用途（你通常想知道"有没有这个键"），但第一次遇到会意外。

**顺带一个写法提醒**：

```python
if "name" in d.keys():           # ❌ 能跑，但 .keys() 是多余的
if "name" in d:                  # ✅ 更短，效果完全一样
```

## 11.4 增和改是同一个语法

**示例 11-7　赋值既是新增也是修改**

```python
d = {"a": 1}

d["b"] = 2                       # 键不存在 → 新增
print(d)                         # => {'a': 1, 'b': 2}

d["a"] = 99                      # 键已存在 → 修改
print(d)                         # => {'a': 99, 'b': 2}
```

**好处**：不用先判断键在不在。

**代价**：**你没法用赋值表达"只在不存在时才写入"**——一不小心就覆盖了已有数据。需要那个语义时用 `setdefault`，或者先 `if k not in d`。

**示例 11-8　字面量里的重复键会静默覆盖**

```python
print({"a": 1, "a": 2})          # => {'a': 2}
```

**不报错，后面的赢。** 手写字面量时不太会犯这个错，但**从两份数据合并字典时，重复键会静默丢数据**——这一点在 11.6 节的 `update` 里同样要注意。

## 11.5 什么能当键

**示例 11-9　键必须可哈希**

```python
d = {}
d["文本"] = 1                     # 字符串 ✅
d[42] = 2                        # 数字 ✅
d[(3, 5)] = "坐标当键"            # 元组 ✅
print(d)                         # => {'文本': 1, 42: 2, (3, 5): '坐标当键'}
```

```python
d[[1, 2]] = "x"
```

```text
TypeError: unhashable type: 'list'
```

**这就是第 10.8 节埋下的伏笔的兑现**：

| 能当键 | 不能当键 |
|---|---|
| 字符串、数字、布尔值 | **列表** |
| 元组（**只装不可变元素的**） | 字典、集合 |
| `frozenset`（第 12 章） | 装了列表的元组 |

**为什么有这个限制**：字典靠"键的哈希值"直接定位数据存放位置。如果键的内容会变，哈希值就变了，之前存的东西就再也找不到了。**所以键必须是不可变的。**

**`(3, 5)` 当键这个用法很实用**——表格坐标、日期组合、复合标识符都能这么用：

```python
board = {}
board[(0, 0)] = "黑棋"
board[(1, 2)] = "白棋"
print(board[(0, 0)])             # => 黑棋
```

**值没有任何限制**——可以是列表、字典、任何东西。

## 11.6 删除与合并

**示例 11-10　三种删除**

```python
d = {"a": 1, "b": 2, "c": 3}

del d["a"]                       # 删一个
print(d)                         # => {'b': 2, 'c': 3}

v = d.pop("b")                   # 删并返回值
print(v, d)                      # => 2 {'c': 3}

print(d.pop("zzz", "没有这个键"))  # => 没有这个键     带默认值，不存在也不报错

d.clear()
print(d)                         # => {}
```

**`del` 和 `pop` 删不存在的键都会报错**：

```python
del {"a": 1}["zzz"]              # ❌ KeyError: 'zzz'
{"a": 1}.pop("zzz")              # ❌ KeyError: 'zzz'
```

**所以 `d.pop(k, None)` 是最安全的删除写法**——不存在也不会崩。

**示例 11-11　合并两个字典**

```python
d1 = {"a": 1, "b": 2}
d2 = {"b": 99, "c": 3}

d3 = dict(d1)                    # 先复制一份，避免改动 d1
d3.update(d2)
print(d3)                        # => {'a': 1, 'b': 99, 'c': 3}     b 被后来的覆盖

print(d1 | d2)                   # => {'a': 1, 'b': 99, 'c': 3}     3.9+ 的写法
print(d1)                        # => {'a': 1, 'b': 2}              原字典没变
```

| 写法 | 行为 |
|---|---|
| `d1.update(d2)` | **原地修改 d1** |
| `d1 \| d2` | **返回新字典**（3.9+），d1 和 d2 都不变 |

**冲突时后来的赢**——这个规则让 `默认配置 | 用户配置` 成为配置合并的标准写法（第 24 章会用到）。

## 11.7 遍历

**示例 11-12　直接遍历得到的是键**

```python
d = {"name": "小明", "age": 18}

for k in d:
    print(k, end=" ")            # => name age 
```

**直接遍历字典，拿到的是键**（不是键值对）。这一点容易搞错。

**示例 11-13　`keys` / `values` / `items`**

```python
d = {"name": "小明", "age": 18}

print(list(d.keys()))            # => ['name', 'age']
print(list(d.values()))          # => ['小明', 18]
print(list(d.items()))           # => [('name', '小明'), ('age', 18)]
```

**注意 `items()` 给的是"元组的列表"**——每个键值对是一个元组。这正好能用第 10.13 节的**解包遍历**：

**示例 11-14　遍历键值对（最常用的形式）**

```python
for k, v in d.items():
    print(f"{k}={v}", end="  ")  # => name=小明  age=18  
```

**这是字典最常用的遍历写法**，值得记牢。

**忘了 `.items()` 会怎样**：

```python
d = {"a": 1, "b": 2}
for k, v in d:
    print(k, v)
```

```text
ValueError: not enough values to unpack (expected 2, got 1)
```

因为直接遍历给的是键（一个字符串 `"a"`），没法拆成两个变量。

## 11.8 遍历时增删会直接报错

**示例 11-15　字典比列表更严格**

```python
d = {"a": 1, "b": 2, "c": 3}
for k in d:
    if k == "a":
        del d[k]
```

```text
RuntimeError: dictionary changed size during iteration
```

**直接报错**，报错信息还很清楚："迭代过程中字典大小改变了"。

**正确做法：遍历副本**

```python
d = {"a": 1, "b": 2, "c": 3}
for k in list(d):                # list(d) 造一个键的列表副本
    if k == "a":
        del d[k]
print(d)                         # => {'b': 2, 'c': 3}
```

### 和第 9 章的列表对比

| | 列表（9.12 节） | 字典 |
|---|---|---|
| 边遍历边删 | **静默出错**——元素被跳过，不报错 | **直接报错** `RuntimeError` |
| 哪个更友好 | —— | **字典更友好**：错误当场暴露，而列表会给你一个错的结果继续跑 |

> **记住这条**：**遍历任何容器时都不要增删它。** 需要修改就遍历副本（`list(d)`）或生成新容器。

## 11.9 判断空字典

**示例 11-16　两种写法**

```python
d = {}
print(len(d))                    # => 0
print(bool(d))                   # => False       空字典是假（第 7.7 节）
```

**所以判断空字典用 `if d:`**：

```python
if d:                            # ✅ 地道
    print("字典有内容")
else:
    print("字典是空的")
```

比 `if len(d) > 0:` 更简洁，而且对所有容器统一。

## 11.10 字典推导式

**示例 11-17　三种典型用法**

```python
scores = {"小明": 92, "小红": 88}

print({v: k for k, v in scores.items()})                    # 键值互换
# => {92: '小明', 88: '小红'}

print({k: v + 5 for k, v in scores.items()})                # 值批量加分
# => {'小明': 97, '小红': 93}

print({k: v for k, v in scores.items() if v >= 90})         # 过滤
# => {'小明': 92}
```

**和列表推导式的区别只有两点**（第 9.16 节）：外面是花括号、里面用 `键: 值` 的形式。

**示例 11-18　用两个列表拼出字典**

```python
names = ["小明", "小红", "小刚"]
nums = [92, 88, 76]

print(dict(zip(names, nums)))            # => {'小明': 92, '小红': 88, '小刚': 76}
print(dict.fromkeys(names, 0))           # => {'小明': 0, '小红': 0, '小刚': 0}
```

**`dict(zip(a, b))` 是"两个列表配对成字典"的标准写法**（`zip` 见第 8.13 节）——**正好解决了开篇那个"两个列表靠下标对应"的脆弱问题**。

`dict.fromkeys(键列表, 初始值)` 造一个"所有键都是同一个初始值"的字典。（它在第 12 章还有个妙用：保序去重。）

## 11.11 嵌套字典：JSON 的形状

**示例 11-19　字典里装字典**

```python
students = {
    "小明": {"数学": 92, "语文": 88},
    "小红": {"数学": 95, "语文": 90},
}

print(students["小明"]["数学"])       # => 92        两层下标
```

**`students["小明"]["数学"]` 的读法**：先取出小明那个字典，再从里面取"数学"。

**遍历嵌套字典**：

```python
for name, subjects in students.items():          # subjects 是内层字典
    total = sum(subjects.values())               # 对内层的值求和
    print(f"{name}: 总分 {total}, 平均 {total / len(subjects):.1f}")
```

```text
小明: 总分 180, 平均 90.0
小红: 总分 185, 平均 92.5
```

**这个结构就是 JSON 的形状。** 从 Web 接口拿到的数据、配置文件里的内容，几乎都是"字典套字典套列表"。**第 17 章会用一行代码把它存成 JSON 文件、再一行读回来**——到那时你会发现，学会嵌套字典就等于学会了处理绝大多数外部数据。

**示例 11-20　嵌套取值别被中间层坑了**

```python
students = {"小明": {"数学": 92}}
print(students["小华"]["数学"])
```

```text
KeyError: '小华'
```

**中间层不存在，还没轮到内层就崩了。**

**安全写法：层层 `get`**

```python
students = {"小明": {"数学": 92}}

print(students.get("小华", {}).get("数学"))          # => None
print(students.get("小华", {}).get("数学", 0))       # => 0
```

**关键是 `get("小华", {})` 的默认值是一个空字典**——这样即使小华不存在，后面的 `.get("数学")` 也有个字典可以调用，不会崩。

> **说实话**：套三层以上（`d.get(a, {}).get(b, {}).get(c)`）就该考虑重新设计数据结构了。太深的嵌套本身就是设计问题。

## 11.12 高频用法①：计数

**示例 11-21　词频统计**（样板示例 · 兑现第 9 章的承诺）

第 9.33 节我们用 `count` 统计词频，当时留了一句"效率很差"。现在给出正确做法：

```python
words = "苹果 香蕉 苹果 橘子 香蕉 苹果".split()

counter = {}
for w in words:
    counter[w] = counter.get(w, 0) + 1       # 关键这一行

print(counter)                                # => {'苹果': 3, '香蕉': 2, '橘子': 1}
```

**核心就是 `counter.get(w, 0) + 1` 这一行**，拆开看：

```python
c = {}
w = "苹果"

c[w] = c.get(w, 0) + 1
print(c)                     # => {'苹果': 1}      第一次：没见过，从 0 起算

c[w] = c.get(w, 0) + 1
print(c)                     # => {'苹果': 2}      第二次：取出 1，加 1
```

**如果不用 `get`，就得先判断**，啰嗦得多：

```python
if w in counter:
    counter[w] = counter[w] + 1
else:
    counter[w] = 1
```

### 和第 9 章的 `count` 对比

| | 第 9 章的 `count` 写法 | 字典写法 |
|---|---|---|
| 结果 | **有重复行**（"苹果"出现三次就打印三次），要自己去重 | **天然去重**，键唯一 |
| 一万个词的工作量 | `count` 每次扫全表 → 约**一亿次**比较 | 扫一遍 → 约**一万次**哈希查找 |

**为什么字典快**：它靠键的哈希值**直接算出数据存在哪儿**，不用逐个比较（这就是 10.8 节"可哈希"的意义）。**耗时几乎和数据量无关**，而 `count` 和数据量成正比。

> **记住这条**：**看到"统计每个 X 出现多少次"，就该想到字典。** 这是字典最经典的用途。
>
> **还能更简单**：标准库的 `collections.Counter` 一行就能做完（`Counter(words)`），第 34 章会讲。**但现在必须先自己写一遍**，否则你不会理解 `Counter` 替你做了什么。

## 11.13 高频用法②：分组

**示例 11-22　按班级分组学生**

```python
records = [("小明", "一班"), ("小红", "二班"), ("小刚", "一班")]

groups = {}
for name, cls in records:                        # 解包遍历（第 10.13 节）
    groups.setdefault(cls, []).append(name)      # setdefault 唯一真正好用的场合

print(groups)                    # => {'一班': ['小明', '小刚'], '二班': ['小红']}
```

**`setdefault(cls, []).append(name)` 这一行做了两件事**：

1. 如果 `cls` 这个键还不存在，先放一个空列表进去
2. 拿到那个列表（不管是刚建的还是已有的），把 `name` 追加进去

**这是 11.2 节说的"`setdefault` 唯一真正好用的场合"**——因为这里我们**就是要**"没有就初始化"这个语义。

**不用 `setdefault` 得这么写**：

```python
for name, cls in records:
    if cls not in groups:
        groups[cls] = []
    groups[cls].append(name)
```

功能一样，多两行。

> **同样有更简单的做法**：`collections.defaultdict(list)` 连 `setdefault` 都不用写（第 34 章）。**但先掌握这个基础写法。**

## 11.14 高频用法③：查找表替代一串 `elif`

**示例 11-23　用字典干掉五个 `elif`**（样板示例）

第 7 章我们只会这么写：

```python
# ❌ 能用，但"有哪些命令"这件事被埋在了逻辑里
if cmd == "add":
    print("添加一条记录")
elif cmd == "del":
    print("删除一条记录")
elif cmd == "list":
    print("列出全部记录")
elif cmd == "help":
    print("显示帮助")
else:
    print("未知命令")
```

**改成查找表**：

```python
# 把"命令 → 说明"这份对应关系单独拿出来——它是数据，不是逻辑
actions = {
    "add": "添加一条记录",
    "del": "删除一条记录",
    "list": "列出全部记录",
    "help": "显示帮助",
}

for cmd in ["list", "xyz", "help"]:
    print(f"{cmd:6} → {actions.get(cmd, '未知命令')}")     # get 的默认值就是原来的 else
```

```text
list   → 列出全部记录
xyz    → 未知命令
help   → 显示帮助
```

**好处非常具体**：

| 方面 | `if/elif` 版 | 查找表版 |
|---|---|---|
| 加一个命令 | 插一段 `elif`，**改逻辑代码** | **加一行数据** |
| 想知道支持哪些命令 | 通读整段代码 | 看字典，或直接列出来 |
| 命令数量到 20 个 | 60 行 `elif` | 字典 20 行 + 逻辑 1 行 |
| 支持"列出所有命令"功能 | 得手工再维护一份 | 遍历字典就行 |

顺手就能加一个功能，`if/elif` 版做不到这么轻松：

```python
print("支持的命令:", ", ".join(actions))      # => 支持的命令: add, del, list, help
print("命令个数:", len(actions))              # => 命令个数: 4
```

（`", ".join(actions)` 直接遍历字典拿到键——回收 11.7 节。）

### 什么时候不该用查找表

**当分支条件不是"等值匹配"而是区间判断时**：

```python
# ❌ 这种情况用不了查找表：键是范围而不是具体值
if score >= 90:
    grade = "优秀"
elif score >= 80:
    grade = "良好"
```

**判断标准**：**能写成"某个值 → 某个结果"的一对一映射，就用字典；需要比大小、判范围，就用 `if`。**

> **记住这条**：**一长串 `elif` 里如果每个条件都是 `x == 某个值`，那它应该是一个字典。**
>
> **这个套路还能走更远**：字典的值不光能存字符串，**还能存函数**——那样连"要执行什么动作"都能查表决定。那是第 14.16 节的内容，也是验收项目 A2（命令行计算器）的核心技巧。

## 11.15 按值排序：做排行榜

**示例 11-24　字典本身不排序，你排的是它的 `items`**

```python
counter = {"苹果": 3, "香蕉": 2, "橘子": 1}

ranked = sorted(counter.items(), key=lambda kv: kv[1], reverse=True)
print(ranked)                    # => [('苹果', 3), ('香蕉', 2), ('橘子', 1)]
print(type(ranked))              # => <class 'list'>        注意结果是列表！
```

**要点**：

1. **`sorted(d.items(), ...)` 的结果是"元组的列表"**，不是字典——字典本身没有"排序"这个操作
2. **`key=lambda kv: kv[1]` 的含义是"按每个键值对的第 2 个元素（也就是值）排"**（`lambda` 完整讲解见第 25 章）
3. `reverse=True` 降序

**配合 `enumerate` 输出排行榜**：

```python
for i, (word, n) in enumerate(ranked, start=1):     # 注意 (word, n) 的括号
    print(f"{i}. {word} {n} 次")
```

```text
1. 苹果 3 次
2. 香蕉 2 次
3. 橘子 1 次
```

**`for i, (word, n) in ...` 这个写法叫"嵌套解包"**——`enumerate` 给出 `(序号, 元组)`，内层的元组再拆成两个变量。

**只想按键排序**就简单得多：

```python
print(sorted(counter))           # => ['橘子', '苹果', '香蕉']
```

（`sorted(字典)` 直接给出排好序的**键列表**。）

## 11.16 `keys()` 是"活的"

**示例 11-25　它不是快照**

```python
d = {"a": 1}
ks = d.keys()
print(ks)                        # => dict_keys(['a'])

d["b"] = 2
print(ks)                        # => dict_keys(['a', 'b'])     跟着变了！
```

**`keys()` / `values()` / `items()` 返回的是"视图对象"**——它们是字典的**实时窗口**，不是当时的副本。

**想要固化成快照，转成列表**：

```python
snapshot = list(d.keys())
d["c"] = 3
print(snapshot)                  # => ['a', 'b']       不变
```

**什么时候会踩到**：以为存下来的是"当时的键列表"，结果它一直跟着字典变。**这也是 11.8 节"遍历副本要写 `list(d)`"的原因**——不转成列表就还是那个活的视图。

## 11.17 字典是有序的（3.7+）

**示例 11-26　按插入顺序遍历**

```python
d = {}
d["z"] = 1
d["a"] = 2
d["m"] = 3

print(d)                         # => {'z': 1, 'a': 2, 'm': 3}
```

**遍历顺序 = 插入顺序**，不是按键排序。这是 **Python 3.7 起的语言保证**。

**为什么要专门讲这个**：

1. **网上大量老教程说"字典是无序的"**——那是 3.6 之前的情况，**现在这个说法过时了**
2. 老代码里的 `collections.OrderedDict` 就是为了这个而存在的（第 34 章会提），现在普通字典就够了

**但注意**：有序**不等于**排序。想按键或值排序，还是得用 11.15 节的 `sorted`。

**示例 11-28　学生成绩管理**

**这是验收项目 A3 的核心结构**——字典套字典：

```python
students = {
    "小明": {"数学": 92, "语文": 88, "英语": 76},
    "小红": {"数学": 95, "语文": 85, "英语": 90},
    "小刚": {"数学": 62, "语文": 70, "英语": 58},
}

subjects = ["数学", "语文", "英语"]                 # 用列表固定列的顺序
line = "-" * 46

print(line)
# 表头：用列表推导式生成各科名字，再拼起来（第 9.16 节）
print(f"{'姓名':<8}" + "".join([f"{s:>7}" for s in subjects]) + f"{'总分':>8}{'平均':>8}")
print(line)

for name, scores in students.items():
    total = sum(scores.values())                  # 对内层字典的值求和
    row = f"{name:<8}" + "".join([f"{scores[s]:>7}" for s in subjects])
    print(row + f"{total:>8}{total / len(scores):>8.1f}")

print(line)

# 各科平均分：对每一科，把所有学生这一科的分数收集起来求平均
print(f"{'各科平均':<8}", end="")
for s in subjects:
    all_scores = [st[s] for st in students.values()]        # 推导式收集这一科的所有分数
    print(f"{sum(all_scores) / len(all_scores):>7.1f}", end="")
print()
```

```text
----------------------------------------------
姓名           数学     语文     英语      总分      平均
----------------------------------------------
小明           92     88     76     256    85.3
小红           95     85     90     270    90.0
小刚           62     70     58     190    63.3
----------------------------------------------
各科平均       83.0   81.0   74.7
```

**三个设计要点**：

1. **用 `subjects` 列表固定列顺序**——虽然字典是有序的（11.17），但显式列出来更清楚，而且方便调整顺序
2. **`sum(scores.values())` 直接对内层字典求和**，不用自己遍历
3. **`[st[s] for st in students.values()]`** 收集"所有学生的某一科分数"——这个"竖着取"的操作用推导式最自然

## 本章易错点

| ❌ 情况 | 症状 | ✅ 解法 | 原因 |
|---|---|---|---|
| `d[k]` 取不存在的键 | `KeyError` | `d.get(k, 默认值)` | `[]` 要求键必须存在 |
| **用 `setdefault` 只为取值** | **字典被意外写入新键** | 只取值用 `get` | `setdefault` 有副作用 |
| `"值" in d` 想查值 | 永远是 `False` | `"值" in d.values()` | `in` 查的是键 |
| `if k in d.keys():` | 能跑，但 `.keys()` 多余 | `if k in d:` | —— |
| **`for k, v in d:`** | `ValueError: not enough values to unpack` | `for k, v in d.items():` | 直接遍历只给键 |
| **遍历字典时增删** | `RuntimeError: dictionary changed size` | 遍历 `list(d)` 副本 | 迭代中结构不能变 |
| 用列表当键 | `TypeError: unhashable type: 'list'` | 改用元组 | 键必须可哈希 |
| `d[k] = v` 想"只在不存在时写" | 覆盖了已有数据 | 先 `if k not in d`，或用 `setdefault` | 赋值不区分新增和修改 |
| 字面量或 `update` 里有重复键 | 前面的**静默丢失** | 检查数据来源 | 后者覆盖前者 |
| `del d[k]` / `d.pop(k)` 删不存在的 | `KeyError` | `d.pop(k, None)` | —— |
| 嵌套取值中间层缺失 | `KeyError`（报的是中间层的键） | `d.get(a, {}).get(b)` | 还没轮到内层就崩了 |
| 以为 `sorted(d)` 能排出字典 | 得到的是**键的列表** | `sorted(d.items(), key=...)` | 字典本身不排序 |
| **把 `keys()` 当快照存起来** | 字典变了它也跟着变 | `list(d.keys())` | 视图对象是"活的" |
| 以为字典无序（看老教程） | 多写了 `OrderedDict` | 3.7+ 普通字典就有序 | 信息过时 |
| 用 `count` 在循环里统计 | 数据量大时慢几个数量级 | 用字典计数 | 全表扫描 vs 哈希查找 |

## 本章小结

- 字典按**名字**取数据（列表按**位置**）；格式 `{键: 值}`
- **取值三法**：`d[k]` 取不到**报错**、`d.get(k, 默认)` 返回默认值、**`setdefault` 会写入字典**
- **`in` 查的是键**；查值要 `in d.values()`
- **键必须可哈希**：字符串、数字、元组可以，**列表不行**（第 10.8 节伏笔的兑现）
- 增和改是**同一个赋值语法**；重复键**静默覆盖**
- 删除用 `del` / `pop`；**`d.pop(k, None)` 最安全**
- **`for k, v in d.items()`** 是最常用的遍历写法；直接遍历只给键
- **遍历时增删会直接 `RuntimeError`**（比列表的"静默出错"更友好）
- **三大高频用法**：计数 `d[k] = d.get(k, 0) + 1`、分组 `setdefault(k, []).append(v)`、**查找表替代一串 `elif`**
- 嵌套字典**就是 JSON 的形状**；嵌套取值用层层 `get`
- 按值排序 `sorted(d.items(), key=lambda kv: kv[1])`，**结果是列表**
- `keys()` 是**活的视图**，不是快照；**3.7+ 字典保证插入顺序**

### 方法速查

| 写法 | 作用 | 注意 |
|---|---|---|
| `d[k]` | 取值 | 取不到 `KeyError` |
| `d.get(k)` / `d.get(k, 默认)` | 安全取值 | **最常用** |
| `d.setdefault(k, 默认)` | 取值，没有就写入 | **有副作用**，只用于分组 |
| `k in d` | 判断键存在 | 查值用 `in d.values()` |
| `d[k] = v` | 新增或修改 | 同一个语法 |
| `d.update(其他)` / `d1 \| d2` | 合并 | 前者原地改，后者返回新字典（3.9+） |
| `del d[k]` | 删除 | 不存在 `KeyError` |
| `d.pop(k, None)` | 删除并返回值 | **最安全的删除** |
| `d.clear()` | 清空 | —— |
| `len(d)` / `if d:` | 个数 / 判空 | —— |
| `d.keys()` / `values()` / `items()` | 键 / 值 / 键值对 | **是活的视图** |
| `for k, v in d.items():` | 遍历键值对 | **最常用的遍历** |
| `{k: v for ...}` | 字典推导式 | —— |
| `dict(zip(a, b))` | 两个列表配对成字典 | —— |
| `dict.fromkeys(键, 初值)` | 批量建键 | 第 12 章还有妙用 |
| `sorted(d.items(), key=lambda kv: kv[1])` | 按值排序 | 结果是**列表** |

### 三大高频用法

| 用途 | 写法 |
|---|---|
| **计数** | `counter[x] = counter.get(x, 0) + 1` |
| **分组** | `groups.setdefault(key, []).append(item)` |
| **查找表** | `actions.get(cmd, 默认值)` 替代一串 `elif` |

## 下一章预告

字典的键有两个特点：**唯一**、**可哈希**。

如果我们只要键、不要值呢？那就是**集合**——一个专门用来"去重"和"求交集并集"的容器。

第 12 章会很轻松，它是阶段一里最短的一章。但它能解决两个你迟早会遇到的问题：

```python
# 一行给列表去重
# 两批数据比对：谁是新增的、谁被删了
```

而且你会看到一个 `{}` 引发的经典陷阱。
