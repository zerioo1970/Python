## 8.1 `for` 循环与可迭代对象

**示例 8-1　逐个字符处理**

```python
for ch in "Python":
    print(ch, end=" ")
```

```text
P y t h o n 
```

**语法结构**：`for 变量 in 可迭代对象:` + 缩进块。

Python 会**自动**从"可迭代对象"里一个一个取出元素，赋给那个变量，然后执行一次循环体——取完就自动结束。

### 什么叫"可迭代对象"

**能一个一个交出元素的东西**，就叫可迭代对象。

你目前学过的可迭代对象：

| 类型 | 交出什么 |
|---|---|
| **字符串** | 一个一个字符 |
| **`range`**（下一节讲） | 一个一个整数 |
| `split()` 的结果 | 一段一段文本（这是**列表**，第 9 章的正题，但现在就能遍历它） |

第 9~12 章的四大容器全都是可迭代对象。**"可迭代"是 Python 里一个贯穿始终的概念**，看到这个词就想到"能放进 `for` 里"。

### 循环变量的命名

```python
for ch in "Python":          # ✅ ch = character，一看就知道是字符
for c in "Python":           # ✅ 也行
for i in "Python":           # ❌ 不好：i 通常表示"序号"，容易误导
```

**惯例**：`i` / `j` 表示序号（index），元素本身要用有意义的名字。

## 8.2 `range`：生成一串数字

**示例 8-2　最常见的用法：重复 N 次**

```python
for i in range(5):
    print(i, end=" ")
```

```text
0 1 2 3 4 
```

**注意从 `0` 开始，到 `4` 结束——不含 5。**

**示例 8-3　`range` 的三种形式**

```python
print(list(range(5)))            # => [0, 1, 2, 3, 4]        只给终点
print(list(range(1, 6)))         # => [1, 2, 3, 4, 5]        给起点和终点
print(list(range(1, 10, 2)))     # => [1, 3, 5, 7, 9]        再给步长
```

（`list()` 只是为了把内容显示出来，下一节解释为什么需要它。）

| 写法 | 含义 |
|---|---|
| `range(5)` | 从 `0` 到 `4` |
| `range(1, 6)` | 从 `1` 到 `5` |
| `range(1, 10, 2)` | 从 `1` 开始，每次加 2，不超过 9 |

**`range` 是"左闭右开"的**——包含起点，不包含终点。**这和第 5.5 节的字符串切片完全一致**。

**为什么 Python 到处都用这个约定**：因为 `range(1, 6)` 的元素个数正好是 `6 - 1 = 5`，一减就知道有几个。**记一次，切片和 range 都会了。**

**示例 8-4　倒着数**

```python
for i in range(3, 0, -1):        # 从 3 开始，每次减 1，不到 0
    print(i, end=" ")
```

```text
3 2 1 
```

**步长为负就是倒序**。注意终点仍然不含——想数到 `0` 得写 `range(3, -1, -1)`。

**说实话，这个写法可读性很差**（三个数字都要在脑子里算一遍）。倒序遍历有更好的办法，见 8.14 的 `reversed`。

## 8.3 `range` 不是列表

**示例 8-5　直接打印 `range` 看不到内容**

```python
print(range(5))              # => range(0, 5)
print(type(range(5)))        # => <class 'range'>
```

**它不是列表，而是一个"按需生成数字"的对象。**

**为什么这么设计**：`range(10**9)` 表示十亿个数字，如果真的生成一个十亿元素的列表，内存直接爆掉。而 `range` 只记住"起点、终点、步长"三个数，用到第几个才算第几个——**几乎不占内存**。

**什么时候会踩到**：想看看里面有什么内容的时候。用 `list()` 包一层就能看：

```python
print(list(range(5)))        # => [0, 1, 2, 3, 4]
```

**但只是为了循环的话，不需要 `list()`**——`for i in range(5)` 直接用就行，而且更省内存。

> 这种"按需生成"的设计在 Python 里很常见，第 30 章（生成器）会系统讲。现在只要知道：**`range` 打印出来看不到数字是正常的**。

## 8.4 遍历元素还是遍历下标

**示例 8-6　两种写法对照**

```python
s = "abc"

# ✅ 地道：直接遍历元素
for ch in s:
    print(ch, end=" ")
print()

# ❌ 不地道：先生成下标，再用下标取元素
for i in range(len(s)):
    print(s[i], end=" ")
print()
```

```text
a b c 
a b c 
```

**结果一样，但第一种明显更好**：

| | 直接遍历 | 用下标 |
|---|---|---|
| 长度 | 短 | 长 |
| 出错可能 | 几乎没有 | 可能写错 `range(len(s)-1)` 之类，导致漏一个或越界 |
| 适用范围 | 所有可迭代对象 | 只有能用下标的（字符串、列表、元组） |

**从 C / Java / C# 转过来的人会本能地写第二种**，因为那些语言的 `for` 就是"计数循环"。**在 Python 里要改掉这个习惯。**

**那什么时候真的需要序号呢？** 用 `enumerate`（8.12 节），不要用 `range(len(...))`。

## 8.5 `while` 循环与三件套

`for` 适合"遍历一批东西"，`while` 适合"条件满足就一直转"。

**示例 8-7　`while` 数到 5**

```python
i = 1                    # ① 初始化
while i <= 5:            # ② 条件
    print(i, end=" ")
    i += 1               # ③ 更新
```

```text
1 2 3 4 5 
```

**`while` 循环必须有三件套**，一个都不能少：

| 要素 | 作用 | 漏了会怎样 |
|---|---|---|
| **① 初始化** | 循环前给变量一个初值 | `NameError` |
| **② 条件** | 每轮开始时检查 | —— |
| **③ 更新** | 让变量朝"条件不成立"的方向变化 | **死循环**（下一节） |

**执行顺序是"先判断，后执行"**——所以条件一开始就不成立时，循环体一次都不执行：

**示例 8-8　条件一次都不成立**

```python
while False:
    print("永远不会执行")

print("循环体一次都没执行")
```

```text
循环体一次都没执行
```

## 8.6 死循环：成因与中断

**示例 8-9　忘了更新变量**（样板示例）

**运行前先记住怎么停下它：按 `Ctrl+C`。**

```python
# ❌ 错误：循环体里没有改变 i，条件永远成立
i = 1
while i <= 5:
    print(i)
```

```text
1
1
1
...（无穷无尽）
```

屏幕会疯狂刷 `1`。按 **`Ctrl+C`** 中断，你会看到：

```text
    print(i)
KeyboardInterrupt
```

**`KeyboardInterrupt` 不是报错，是"你手动打断了程序"的提示。**

原因很简单：`while` 每轮开始时检查 `i <= 5`，而循环体里 `i` 从头到尾都是 `1`，条件永远成立。

```python
# ✅ 正确：补上更新
i = 1
while i <= 5:
    print(i)
    i += 1               # ← 漏掉这一行就是死循环
```

### 死循环的三种成因

遇到死循环，按这个顺序查：

| 成因 | 例子 | 怎么查 |
|---|---|---|
| **① 忘了更新循环变量** | 上面这段 | 在循环里 `print(i)`，看它有没有在变 |
| **② 条件永远为真** | `while 1 > 0:` 且循环体里没有 `break` | 检查条件里有没有会变化的变量 |
| **③ 更新方向写反** | `while i > 0:` 里写了 `i += 1` | 看变量是在朝"让条件不成立"的方向走吗 |

> **记住这条**：**写 `while` 时，先把更新那一行写出来**，再写循环体的其他内容。顺序反了就容易忘。
>
> **`for` 循环为什么不会死循环**：它的"更新"是 Python 自动做的——按顺序取下一个，取完就结束。**这就是"能用 `for` 就别用 `while`"的原因。**

## 8.7 `for` 和 `while` 怎么选

| 情况 | 用哪个 | 例子 |
|---|---|---|
| **有明确的遍历对象** | `for` | 处理一段文本的每个字符、处理一批数据 |
| **次数已知** | `for` + `range` | 重复 10 次 |
| **不知道要转几次，由条件决定** | `while` | 反复问到用户输对为止、算到结果收敛为止 |
| **条件要在循环体中间才能判断** | `while True` + `break` | 交互式菜单（8.10 节） |

**判断口诀**：**"遍历"用 `for`，"直到"用 `while`。**

## 8.8 `break`：提前退出

**示例 8-10　找到就停，不用把整批走完**

```python
for ch in "Python":
    if ch == "h":
        break                    # 立刻跳出整个循环
    print(ch, end=" ")

print("← break 在 h 处停了")
```

```text
P y t ← break 在 h 处停了
```

**`break` 立刻结束整个循环**，后面的元素一个都不再处理。

**什么时候用**：**找到目标了，没必要继续找**。在一万条数据里找一条，找到就 `break`，能省掉大量无用的循环。

## 8.9 `continue`：跳过本轮

**示例 8-11　跳过不合格的数据**

```python
for ch in "a b c":
    if ch == " ":
        continue                 # 跳过本轮剩下的语句，直接进入下一轮
    print(ch, end=" ")

print("← continue 跳过了空格")
```

```text
a b c ← continue 跳过了空格
```

**`continue` 只跳过本轮，循环还在继续。**

**这是新手最容易混淆的一对**：

| | `break` | `continue` |
|---|---|---|
| 作用 | **结束整个循环** | **跳过本轮，继续下一轮** |
| 后面的元素 | 不再处理 | 继续处理 |
| 典型用途 | 找到了就停 | 过滤掉不需要的 |

**`continue` 的实用价值是"提前挡掉"**：与其写 `if 合格: 处理`（多一层缩进），不如写 `if 不合格: continue`（主流程留在最外层）。这是第 7.12 节扁平化思想在循环里的应用，本章末的输入校验会用到。

## 8.10 `while True` + `break` 骨架

**这是交互式程序的标准结构**，值得单独讲。

**示例 8-12　为什么需要"无限循环"**

有些情况下，"要不要继续"这个判断**只能在循环体中间做**——比如"问用户要什么，如果用户说退出就结束"。

```python
while True:                      # 条件永远成立，看起来像死循环
    cmd = input("请输入命令（quit 退出）：").strip().lower()

    if cmd == "quit":
        print("再见")
        break                    # ← 靠 break 退出，不是靠条件

    print(f"你输入了：{cmd}")
```

**`while True` 是合法且常用的写法**，不是坏味道——只要循环体里**一定有 `break`**。

**为什么不写成 `while cmd != "quit"`**：因为进入循环前 `cmd` 还不存在，得先在外面写一遍 `input`，代码就重复了。

> **记住这条**：**`while True` + `break` 是交互式程序的标准骨架。** 唯一要小心的是——**必须确保 `break` 会被执行到**，否则就真成死循环了。

## 8.11 累加器模式

循环最常见的用途是"**把一批数据算成一个结果**"——求和、计数、找最值。它们都是同一个模式：**循环外初始化，循环内累积。**

**示例 8-13　求和**

```python
total = 0                        # ① 循环外初始化
for ch in "12345":
    total += int(ch)             # ② 循环内累积

print("求和:", total)             # => 求和: 15
```

**示例 8-14　计数**

```python
count = 0
for ch in "a1b2c3":
    if ch.isdigit():             # 只数数字字符
        count += 1

print("数字字符个数:", count)      # => 数字字符个数: 3
```

**示例 8-15　找最大值**

```python
s = "3 9 2 7"
biggest = float("-inf")          # 初始值：负无穷，任何数都比它大

for part in s.split():           # split() 的结果也能遍历（列表见第 9 章）
    if int(part) > biggest:
        biggest = int(part)

print("最大值:", biggest)         # => 最大值: 9
```

### 找最值的初始值陷阱

**示例 8-16　初始值设 `0` 会错**

```python
s = "-3 -9 -2"                   # 全是负数

# ❌ 错误：初始值设 0
wrong = 0
for part in s.split():
    if int(part) > wrong:
        wrong = int(part)
print("初始值设 0 →", wrong)       # => 初始值设 0 → 0
```

**结果是 `0`，而 `0` 根本不在数据里！** 因为没有任何负数大于 0，`wrong` 从头到尾没被更新过。

```python
# ✅ 正确：用负无穷做初始值
right = float("-inf")
for part in s.split():
    if int(part) > right:
        right = int(part)
print("初始值设 -inf →", right)    # => 初始值设 -inf → -2
```

**两种正确做法**：

| 做法 | 写法 | 说明 |
|---|---|---|
| 用负无穷 | `float("-inf")` | 找最小值用 `float("inf")` |
| 用第一个元素 | 先取第一个，再从第二个开始比 | 更严谨，但代码稍长（需要列表操作，第 9 章） |

> **记住这条**：**找最值时，初始值不能拍脑袋写 `0`。** 用 `float("-inf")` / `float("inf")`，或者用数据里的第一个元素。

### 顺便说：这些以后有一行写法

第 9 章会学到 `sum()`、`max()`、`min()`、`len()`，上面这些循环都能压成一行。

**那为什么现在要手写？** 因为**不手写一遍，你不会理解"结果是怎么攒出来的"**。而且累加器模式的适用范围远超这几个函数——统计"符合某个条件的个数"、"累计到超过某个阈值为止"，都得自己写循环。

## 8.12 `enumerate`：同时要序号和内容

8.4 节说过，需要序号时**不要用 `range(len(...))`**。正确做法是 `enumerate`：

**示例 8-17　同时拿到位置和元素**

```python
s = "abc"

for i, ch in enumerate(s):
    print(i, ch, end="  ")
```

```text
0 a  1 b  2 c  
```

**`enumerate` 每轮交出两个值**：序号和元素。用两个变量接住（这个写法叫"解包"，第 10 章会正式讲）。

**示例 8-18　让序号从 1 开始**

```python
for i, ch in enumerate("abc", start=1):
    print(i, ch, end="  ")
```

```text
1 a  2 b  3 c  
```

**`start=1` 在打印清单时很有用**——给人看的编号通常从 1 开始。

**和 `range(len(s))` 对比**：

```python
# ❌ 不地道
for i in range(len(s)):
    print(i, s[i], end="  ")

# ✅ 地道
for i, ch in enumerate(s):
    print(i, ch, end="  ")
```

后者更短、不会写错下标、而且**对所有可迭代对象都适用**（`range(len(...))` 只能用于支持下标的类型）。

## 8.13 `zip`：并行遍历两批数据

**示例 8-19　把两批数据配对**

```python
for a, b in zip("123", "abc"):
    print(a, b, end="  ")
```

```text
1 a  2 b  3 c  
```

**`zip` 把两个（或多个）可迭代对象"拉链式"配对**——各取第一个配一对，各取第二个配一对，以此类推。

**典型场景**：学号和姓名分别存在两批数据里，要一一对应处理。

### 长度不等时会静默丢数据

**示例 8-20　这是个隐蔽的坑**

```python
for a, b in zip("12345", "ab"):
    print(a, b, end="  ")

print("← 后面的 345 被丢了")
```

```text
1 a  2 b  ← 后面的 345 被丢了
```

**`zip` 以最短的那个为准，多出来的部分被无声丢弃**——不报错、不警告。

**为什么这很危险**：如果两批数据本该等长（比如学号和姓名），一方少了几条说明数据有问题，而 `zip` 会帮你把问题藏起来。

**Python 3.10+ 提供了 `strict=True`**：

```python
list(zip("12345", "ab", strict=True))
```

```text
ValueError: zip() argument 2 is shorter than argument 1
```

**长度不等就直接报错**，把问题暴露出来。

> **记住这条**：**两批数据本该等长时，用 `zip(a, b, strict=True)`。** 让错误早点暴露，比拿着丢了数据的结果继续跑好得多。

## 8.14 `reversed`：倒着遍历

**示例 8-21　倒序的两种写法**

```python
for ch in reversed("abc"):
    print(ch, end=" ")
print()

for i in range(2, -1, -1):       # 用 range 负步长也能倒序
    print(i, end=" ")
print("← range 负步长的可读性差多了")
```

```text
c b a 
2 1 0 ← range 负步长的可读性差多了
```

**`reversed(x)` 比 `range(len(x)-1, -1, -1)` 好读太多**——后者三个参数都要在脑子里算一遍。

**和切片 `[::-1]` 的区别**（第 5.9 节）：

| 写法 | 行为 |
|---|---|
| `reversed(s)` | 返回一个"倒着取"的可迭代对象，**不复制数据** |
| `s[::-1]` | **造一个新的**反转字符串 |

**只是要遍历就用 `reversed`（省内存）；需要一个反转后的字符串就用 `[::-1]`。**

## 8.15 嵌套循环

循环里可以套循环。

**示例 8-22　打印一个矩形**

```python
for row in range(3):             # 外层：3 行
    for col in range(5):         # 内层：每行 5 个
        print("*", end="")       # end="" 让同一行的星号连着
    print()                      # 内层循环结束后换行
```

```text
*****
*****
*****
```

**执行次数是乘法关系**：外层 3 次 × 内层 5 次 = 内层循环体执行 15 次。

**这个乘法关系是性能问题的起点**——外层 1000 次、内层 1000 次就是一百万次。数据量大时嵌套循环要格外小心（专项 B 会讲怎么测）。

**示例 8-23　九九乘法表**

```python
for i in range(1, 4):                          # 只打前三行做示例
    for j in range(1, 10):
        print(f"{i}x{j}={i*j:<4}", end="")     # :<4 左对齐占 4 格，让列对齐
    print()
```

```text
1x1=1   1x2=2   1x3=3   1x4=4   1x5=5   1x6=6   1x7=7   1x8=8   1x9=9   
2x1=2   2x2=4   2x3=6   2x4=8   2x5=10  2x6=12  2x7=14  2x8=16  2x9=18

```

## 8.16 `break` 只跳出一层

**示例 8-24　这是嵌套循环最大的坑**

```python
# ❌ 以为 break 能跳出双层
for i in range(3):
    for j in range(3):
        if j == 1:
            break                # 只结束了内层循环
        print(f"({i},{j})", end=" ")
```

```text
(0,0) (1,0) (2,0) 
```

**外层循环照样转完了三轮。** 因为 `break` 的定义就是"结束**当前所在的**那个循环"。

**正确做法：用标志变量**

```python
# ✅ 用一个变量记录"要不要退出外层"
found = False

for i in range(3):
    for j in range(3):
        if i == 1 and j == 1:
            found = True
            break                # 先跳出内层
        print(f"({i},{j})", end=" ")
    if found:                    # 回到外层后再判断一次
        break                    # 跳出外层
```

```text
(0,0) (0,1) (0,2) (1,0) 
```

**Python 没有"带标签的 break"**（Java 有 `break label`），也没有 `goto`。所以跳出多层只有两个办法：

| 办法 | 说明 |
|---|---|
| **标志变量** | 上面这种，能用但略啰嗦 |
| **抽成函数用 `return`** | **更干净**——`return` 直接结束整个函数，多少层都跳得出来。第 14 章会讲 |

> **记住这条**：**`break` 只结束当前循环。** 需要跳出多层时，标志变量能解决；等学了函数（第 14 章），用 `return` 更利索。

## 8.17 循环的 `else` 子句

**这是 Python 特有的语法**，其他语言基本没有，所以第一次见到会很困惑。

**规则**：**循环正常结束（没被 `break` 打断）时，执行 `else`。**

**示例 8-25　"找遍了都没找到"**

```python
for ch in "abc":
    if ch == "z":
        print("找到了")
        break
else:
    print("找遍了都没找到 → else 执行了")
```

```text
找遍了都没找到 → else 执行了
```

对比一下找到的情况：

```python
for ch in "abz":
    if ch == "z":
        print("找到了 z")
        break
else:
    print("这行不会执行")
```

```text
找到了 z
```

**`else` 的语义是"循环跑完了都没 `break`"**——用来处理"查找失败"这类情况，省掉一个标志变量。

**`while` 也有 `else`**，而且有个很实用的场景（本章末的猜数字会用到）：

```python
while count < MAX_TRIES:
    ...
    if 猜对了:
        break
else:
    print("机会用完了")           # 次数耗尽而不是猜对退出
```

> **说实话**：这个语法**争议很大**。反对的理由是 `else` 这个词在这里的含义不直观（它是"没 break"而不是"条件不成立"），很多团队规范里直接禁用它。
>
> **本书的建议**：**要能读懂**（别人代码里出现时不困惑），**但不建议主动用**——用标志变量或把逻辑抽成函数（第 14 章）通常更清楚。

## 8.18 循环变量的作用域

**示例 8-26　循环结束后，循环变量还活着**

```python
for i in range(3):
    pass

print("循环结束后 i =", i)        # => 循环结束后 i = 2
```

**循环变量在循环结束后依然存在**，值是最后一次的值。**这和 C# / Java 不同**——那些语言里 `for` 的计数变量只在循环内可见。

**这个特性有时有用**（第 7 章那个输入校验就靠它——循环里赋的 `age`，循环外还能用），但也有个坑：

```python
for i in range(0):               # 一次都不执行
    pass

print(i)
```

```text
NameError: name 'i' is not defined. Did you mean: 'id'?
```

**循环体一次都没执行时，循环变量根本没被创建。**

**什么时候会踩到**：处理"可能为空"的数据时。如果循环可能一次都不执行，而你在循环后要用循环变量，就得**先在循环外给它一个初值**。

## 综合示例

**示例 8-27　输入校验重试**（样板示例 · 兑现第 6 章的承诺）

第 6 章我们只能"假设用户会老实输入数字"。现在有了循环，可以真的做到"输错就重新问"：

```python
while True:                                   # 合法的无限循环：条件要在循环体中间才能判断
    raw = input("请输入年龄（0-120）：").strip()   # strip 必做，用户很容易多敲空格

    if not raw.isdigit():                     # isdigit 能挡住字母和空输入（第 6.15 节）
        print("请输入数字，不要输入其他字符")
        continue                              # 提前挡掉，主流程留在最外层缩进

    age = int(raw)                            # 走到这里 raw 一定能转成整数，转换是安全的

    if age > 120:                             # 范围检查是第二道关，和格式检查分开写
        print("年龄不能超过 120")
        continue

    break                                     # 两道关都过了，跳出循环

print(f"你的年龄是 {age} 岁")                   # 循环里赋值的 age，循环外依然可用（见 8.18）
```

依次输入 `abc`、直接回车、`200`、`35`：

```text
请输入年龄（0-120）：abc
请输入数字，不要输入其他字符
请输入年龄（0-120）：
请输入数字，不要输入其他字符
请输入年龄（0-120）：200
年龄不能超过 120
请输入年龄（0-120）：35
你的年龄是 35 岁
```

**三个值得单独说的设计**：

1. **格式检查和范围检查分开写**，各配各自的提示语。合成一个 `if` 也能跑，但用户就不知道自己错在哪。
2. **用 `continue` 而不是嵌套 `if`**。如果写成"格式对了就进去检查范围"，会多一层缩进；用 `continue` 提前挡掉不合格的输入，**主流程始终在最外层**——这是第 7.12 节扁平化思想的应用。
3. **`break` 放在所有检查之后**，它的位置就代表"全部通过"。

> **这段代码还不够好**：`isdigit()` 挡不住负数和小数（第 6.15 节讲过），要正确处理得用第 15 章的 `try`。**到时候我们会回来把这段重写一遍，代码会更短也更可靠。**
>
> **记住这条**：**`while True` + 校验 + `continue` + `break` 是交互式输入的标准骨架**，闭着眼睛都要能写出来。

**示例 8-28　猜数字游戏**

**这就是验收项目 A1 的核心**，你的第一个游戏：

```python
import random                                  # 标准库，随机数；工具箱 T2 详讲

target = random.randint(1, 100)                # 随机生成 1~100 的整数（两端都含）
count = 0                                      # 计数器：记录猜了几次

print("我想好了一个 1~100 的数字，你来猜")

while True:
    guess = int(input("你猜是多少？").strip())     # 暂时假设用户输入合法（第 15 章解决）
    count += 1

    if guess < target:
        print("小了")
    elif guess > target:
        print("大了")
    else:
        print(f"猜对了！你用了 {count} 次")
        break                                  # 猜对了才退出
```

一次真实的对局（**你运行时答案会不同**）：

```text
我想好了一个 1~100 的数字，你来猜
你猜是多少？50
小了
你猜是多少？75
小了
你猜是多少？88
大了
你猜是多少？82
猜对了！你用了 4 次
```

**注意上面的猜法**：50 → 75 → 88 → 82，每次都往"还没排除的范围"的中间猜。这叫**二分查找**，1~100 最多 7 次必中。（第 20.12 节会讲这个思路在排错时的应用。）

**加上次数上限——`while...else` 的实用场合**：

```python
import random

target = random.randint(1, 100)
count = 0
MAX_TRIES = 3                                  # 大写表示"当常量用"（第 2.5 节）

print(f"我想好了一个 1~100 的数字，你有 {MAX_TRIES} 次机会")

while count < MAX_TRIES:
    guess = int(input("你猜是多少？").strip())
    count += 1

    if guess < target:
        print("小了")
    elif guess > target:
        print("大了")
    else:
        print(f"猜对了！你用了 {count} 次")
        break
else:
    print(f"机会用完了，答案是 {target}")          # 次数耗尽才执行（8.17）
```

```text
我想好了一个 1~100 的数字，你有 3 次机会
你猜是多少？50
小了
你猜是多少？60
小了
你猜是多少？70
小了
机会用完了，答案是 82
```

**这是 `while...else` 少有的"确实好用"的场景**：`else` 精确表达了"**不是猜对退出，而是次数耗尽**"这个区别。如果不用 `else`，就得在循环外再判断一次 `if count == MAX_TRIES`。

**示例 8-29　打印金字塔**

嵌套循环的经典练习，重点是**找出规律**：

```python
n = 5

for row in range(1, n + 1):                    # 行号从 1 数到 n
    # 规律：第 row 行有 (n - row) 个空格、(2 * row - 1) 个星号
    print(" " * (n - row) + "*" * (2 * row - 1))
```

```text
    *
   ***
  *****
 *******
*********
```

**怎么找出这个规律**（这个思考过程比代码本身重要）：

| 行号 | 空格数 | 星号数 | 观察 |
|---|---|---|---|
| 1 | 4 | 1 | 空格 = 5 - 1；星号 = 2×1 - 1 |
| 2 | 3 | 3 | 空格 = 5 - 2；星号 = 2×2 - 1 |
| 3 | 2 | 5 | 空格 = 5 - 3；星号 = 2×3 - 1 |
| 4 | 1 | 7 | ... |
| 5 | 0 | 9 | 空格 = 5 - 5；星号 = 2×5 - 1 |

**先把前几行的数字列出来找规律，再写代码**——这是解决这类问题的通用方法。直接想公式很容易想错。

（这里用了字符串乘法 `" " * n` 代替内层循环，比嵌套两层 `for` 更简洁。第 5 章学过这个写法。）

<details>
<summary><b>给有 C# / Java / SQL 经验的读者</b></summary>

| 你熟悉的 | Python |
|---|---|
| `for (int i = 0; i < 5; i++)` | `for i in range(5):` |
| `foreach (var x in list)` | `for x in lst:` |
| `for (int i = 0; i < s.Length; i++) s[i]` | **`for ch in s:`**（别用 `range(len(s))`） |
| `while (cond) { }` | `while cond:` |
| `do { } while (cond)` | **没有 do-while**，用 `while True` + 末尾 `if not cond: break` |
| `break` / `continue` | 同名，行为相同 |
| `break label`（跳出多层） | **没有**——用标志变量，或抽函数用 `return`（第 14 章） |
| `i++` / `i--` | **没有**，写 `i += 1` |
| 计数变量作用域仅限循环内 | **循环后依然可见**（值是最后一次的值） |
| `for (a, b) in zip(...)` 需要额外库 | `zip(a, b)` 内置 |
| —— | **`for...else`**：循环没被 break 时执行（Python 独有） |

**四个需要注意的**：

1. **没有三段式 `for`。** Python 的 `for` 只有"遍历"一种形态。想要计数就用 `range`，想同时要序号和元素就用 `enumerate`——**不要写 `for i in range(len(x))`**，那是把 C 的习惯搬过来。
2. **没有 `do-while`。** 需要"先执行一次再判断"时，用 `while True` 加末尾 `break`。
3. **没有带标签的 break。** 跳出双层循环只能靠标志变量或函数 `return`。
4. **循环变量的作用域更宽。** 循环结束后还能用它——这个特性有时方便（本章 8-27 就靠它），但如果循环可能一次都不执行，用之前要先在外面赋初值。

**SQL 背景的读者**：SQL 是"声明式"的（描述你要什么），而循环是"命令式"的（描述怎么一步步做）。习惯了 `SELECT ... WHERE` 之后，会觉得写循环很啰嗦——这个感觉是对的。Python 也有更接近声明式的写法（**列表推导式**，第 9 章；`sum` / `max` 等聚合函数，第 9 章），学到那里你会更舒服。

</details>

## 本章易错点

| ❌ 情况 | 症状 | ✅ 解法 | 原因 |
|---|---|---|---|
| `while` 里忘了更新循环变量 | **死循环**，屏幕疯狂刷屏 | `Ctrl+C` 中断，补上 `i += 1` | 条件永远成立 |
| 更新方向写反 | 死循环 | 检查变量是否朝"条件不成立"走 | `i > 0` 配 `i += 1` 永不结束 |
| 以为 `continue` 会跳出循环 | 循环没停，逻辑错乱 | 跳出用 `break` | 两者语义完全不同 |
| **内层 `break` 想跳出双层** | 外层还在继续转 | 标志变量，或抽函数用 `return`（第 14 章） | `break` 只结束当前循环 |
| `for i in range(len(s)): s[i]` | 能跑但不地道，容易写错下标 | `for ch in s:` 或 `enumerate(s)` | Python 直接遍历元素 |
| **`zip` 两个长度不等的序列** | 多出来的数据被**静默丢弃** | 3.10+ 用 `zip(a, b, strict=True)` | `zip` 以最短为准 |
| **找最值初始值设 `0`** | 全是负数时结果错成 `0` | 用 `float("-inf")` 或第一个元素 | `0` 不是"最小可能值" |
| `range(1, 5)` 以为含 5 | 少循环一次 | 要含 5 写 `range(1, 6)` | 左闭右开 |
| `print(range(5))` 想看内容 | 输出 `range(0, 5)` | `list(range(5))` | `range` 是按需生成的 |
| 循环体忘了缩进 | `IndentationError`，或语句跑到循环外只执行一次 | 检查缩进 | 缩进决定归属 |
| 循环可能一次不执行还用循环变量 | `NameError` | 循环外先赋初值 | `range(0)` 时变量不会被创建 |
| 嵌套循环内外层用同一个变量名 | 外层计数被内层改掉，结果诡异 | 内外层用不同名字（`i` / `j`） | 变量互相覆盖 |
| `while True` 里没有 `break` | 真的死循环 | 确保 `break` 会被执行到 | —— |
| 用 `for...else` 但团队看不懂 | 代码评审被打回 | 用标志变量代替 | 这个语法争议大 |

## 本章小结

- `for 变量 in 可迭代对象:`——**可迭代对象 = 能一个一个交出元素的东西**
- `range(起, 止, 步)` **左闭右开**（和切片一致）；**`range` 不是列表**，打印看不到内容
- **不要写 `for i in range(len(x))`**——直接遍历元素，需要序号用 `enumerate`
- `while` **三件套**：初始化、条件、更新；**漏了更新就是死循环**（`Ctrl+C` 中断）
- **"遍历"用 `for`，"直到"用 `while`**
- `break` **结束整个循环**、`continue` **跳过本轮**；**`break` 只跳一层**
- **`while True` + `break`** 是交互式程序的标准骨架
- **累加器模式**：循环外初始化、循环内累积；**找最值别拿 `0` 当初始值**
- `enumerate` 拿序号、`zip` 并行遍历（**长度不等会静默丢数据，用 `strict=True`**）、`reversed` 倒序
- 嵌套循环的次数是**乘法关系**；循环变量在**循环结束后依然存在**

### 语法速查

| 写法 | 作用 |
|---|---|
| `for x in 可迭代对象:` | 遍历 |
| `for i in range(n):` | 重复 n 次（`0` 到 `n-1`） |
| `range(a, b)` / `range(a, b, step)` | 指定起止 / 步长；**左闭右开** |
| `while 条件:` | 条件成立就一直转 |
| `while True:` + `break` | 交互式骨架 |
| `break` | 结束整个循环（**只一层**） |
| `continue` | 跳过本轮 |
| `for i, x in enumerate(seq):` | 同时拿序号和元素 |
| `enumerate(seq, start=1)` | 序号从 1 开始 |
| `for a, b in zip(x, y):` | 并行遍历 |
| `zip(x, y, strict=True)` | 长度不等时报错（3.10+） |
| `for x in reversed(seq):` | 倒序遍历 |
| `for ... else:` | 循环没被 `break` 时执行（★ 争议语法） |
| `float("-inf")` / `float("inf")` | 找最值的安全初始值 |
