## 这份教程的几个特点

- **报错优先**：第 2 章就教读 Traceback，而不是留到最后
- **所有输出都实跑核对**：`tools/check_outputs.py` 自动校验正文里标注的每一处输出
- **坑点前置**：深浅拷贝、`is` 与 `==`、浮点精度、`w` 模式清空文件等，都在会踩到之前讲
- **不讲面试八股**：元类、GIL、垃圾回收下沉到选修专项并明确标注
- **承诺兑现链**：前面故意用"不够好的写法"，学了新工具后回来重写同一段代码

## 环境要求

Python **3.10+**（推荐 3.12 / 3.13）。主线用到的第三方库仅 `requests`、`pytest`、`ruff`、`mypy`。
